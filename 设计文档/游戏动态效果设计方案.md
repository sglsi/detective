## 2. 核心设计思路

**把"一张背景图"理解为"场景要素清单"**：图中的门、壁炉、窗、灯、家具拆成独立节点，叠上程序化基底、着色器氛围、角色 Juice 与镜头调度。

- 每个要素可独立动画（门可开、灯可闪、窗帘可摇）；
- 氛围可随剧情/玩法实时切换（取证成功→房间变亮、终局→暗角收紧）；
- 角色不需骨骼，靠差分 + Tween 做到 AVG 级演出；
- **镜头是"第二叙事者"**：推近制造焦点，框选保证信息完整。


## 4. 角色演出方案（不用骨骼）

### 4.1 为什么放弃 rig
`sherlock/rig`、`watson/rig` 已无实际 PNG，只剩 `.import` 空桩（**已清理**）。2D 骨骼需专业分层美术 + 逐顶点权重 + 关键帧动画，AI 自动切部件方案在这三项上先天缺陷，投入产出比极低。

### 4.2 采用：差分立绘 + Juice
- `PortraitLibrary`：按 `speaker + mood` 取表情差分；
- `assets/characters/watson/`：18+ 张差分（倾佩/兴奋/凝思/吃惊/喜悦）与姿态变体；
- `assets/characters/holmes/`：14 张像素表情差分。

### 4.3 Juice 层（✅ = 已落地）

| 效果 | 实现 | 状态 |
|------|------|------|
| 说话呼吸 bob | `position.y ± 3px` + 缩放 1.0→1.01 循环 | ✅ |
| 出场滑入 | 侧边偏移 + 缩放 + 淡入，`Back.out` 回弹 | ✅ |
| 情绪爆发 | 快速缩放回弹 + 旋转 ±5° | ❌ 待做 |
| 被指认/震惊 | 角色推近 + 红/白闪 + 抖动 | ❌ 待做 |

### 5.1 氛围动态

| 效果 | 实现 | 状态 |

| scene3 | 1.00 | 0.24 | 暖褐 | 2 盏 | 1.1 |
| scene4 | 1.10 | 0.34 | 冷蓝 | 2 盏 | 1.2 |
| scene5 | 1.00 | 0.22 | 暖褐 | 2 盏 | 1.1 |

### 5.2 镜头系统（v1.0 方案缺失，本章为补充）

镜头是本作已成型的核心动态能力，但原方案未系统描述。现有 API（`scene_framework.gd`）：

| API | 用途 | 典型调用 |
|---|---|---|
| `focus_world_point(pt, zoom)` | 单点推近 | 聚焦某个刚发现的线索 |
| `frame_world_points(points, padding)` | **多点框选**：算点集包围盒→适配缩放居中，保证所有目标在视野内 | 通用工具（"一组目标都可见"时调用）；收集线索流程现改回 `reset_camera()` |
| `reset_camera()` | 回统览（zoom=1） | 阶段结束、切图前 |
| `set_camera_enabled(b)` | 锁/放玩家拖拽滚轮 | 演出期间锁输入，避免与推镜打架 |

> ⚠️ **历史缺陷回顾**：早期在收集线索后调用 `focus_world_point` 锁推近"刚记录的线索"，
> 结果把其余待收集圆圈推出视口，玩家点不到而卡关 → 已改回 `reset_camera()` 平滑回到统览（zoom=1 全可见）。
> `frame_world_points()` 仍保留作"让一组目标都在视野内"的通用工具（非收集流程使用）。
> 调用点变更：`scene1._on_collect_clue`、基类 `detective_scene._on_clue_recorded` 现均调用 `reset_camera()`（2026-09-12 回退 32d3484 的框选方案，因其每次收集都推近/缩回、观感生硬）。

### ✅ Tier 1.5：低成本补强 —— 已完成（2026-09-12，零美术）

不改架构、只补观感，风险极低：

| 项 | 做法 | 收益 |
|---|---|---|
| **场景/背景转场** | 切图时用 `Tween` 做 0.3–0.5s 黑场或交叉淡入 | 消除硬切割裂感，立刻"像成品" |
| **热点脉冲** | `hotspot_area.gd` 加呼吸 Tween（缩放/透明度循环） | 新手一眼看到可点处 |
| **取证即时反馈** | 线索入册时：圆圈炸开粒子 + 短暂高亮 + 轻微震屏 | 正反馈爽感（配合已有的 clue_found 音效） |
| **情绪爆发 Juice** | 情绪 mood 为 shock/angry 时，立绘快速缩放回弹 + 旋转 ±5° | 强化戏剧张力 |
| **镜头呼吸** | 空闲时主镜头极缓慢缩放（±0.5%） | 画面不死板 | ✅ |

**全部 5 项已落地**（其中「热点脉冲」经查本就已有，无需新增）。实现要点与避坑：

- **情绪爆发只动 `position:x`**，呼吸 bob 只动 `position:y` —— 两个 Tween 不争抢同一属性，不会互相打断。
- **取证光环**设在 `_remove_clue_circle`：原位生成一圈扩散光环（放大 2× + 淡出 0.36s），与 `clue_found` 音效同步；必须设 `pivot_offset = center`，否则 Control 以左上角为原点缩放会导致整体偏移。
- 光环唯一调用点是 `_close_zoom`（线索成功收集），**不会在清场/切阶段时误触发**。
- **镜头呼吸触发条件刻意收紧**：相机启用 + 未拖拽 + 无相机 Tween 运行 + zoom≈1（统览态），防止与推镜/滚轮打架；幅度仅 ±0.5%、周期 9s。
- **背景交叉淡化**：旧背景改名 `scene_bg_old` 淡出、新背景淡入（各 0.35s），氛围层同步 0.5s 淡入；开头先清理上一次的淡出残留，避免连续切图时堆积。

## 8. 关于 scene1 拆分图（`场景01 拆分.png`）的评估

### 8.1 图的内容
11 个独立像素风家具要素：壁炉（带烛台/炉架）、铺桌布的餐桌、木椅、高书柜、床头柜+绿色台灯、小书柜、花纹窗帘（一对）、金色边框镜子、风景画框、红色波斯地毯、黄铜烛台、绿色台灯（另一角度）。

**优点**：已透明底可直接当 `Sprite2D`；像素风格统一；要素完整；与"拆分真实要素"目标吻合。

**风险**：
1. **风格不匹配**：现有 `screen01-sofa01.png` 是写实/厚涂风，拆分图是像素风，直接拼贴会割裂；
2. **缺关键元素**：沙发、壁炉上方装饰、角色座椅需补；
3. **无坐标/比例**：需按 1920×1080 基准重新缩放定位。

### 8.2 使用建议

| 方案 | 做法 | 成本 | 效果 |
|------|------|------|------|
| A. 直接使用 | 11 件家具拼到 sofa 背景 | 最低 | **风险高**：风格割裂 |
| B. 统一成像素风 | 底图也重渲成像素 | 中等 | 风格统一，整体变像素 AVG |
| C. 重写实风要素 | 以拆分图为清单，按现有底图风格重生成要素 | 中等 | **与现有背景无缝融合，效果最好** |
| **推荐** | **C 方案**：拆分图作为"拆什么"的蓝图，而非直接美术资源 | — | 风格一致 + 要素完整 |
