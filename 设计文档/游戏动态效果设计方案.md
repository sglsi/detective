# 游戏动态效果设计方案

> 目标：将当前"一张静态背景图 + 静态立绘"的演出方式，升级为"真实场景要素 + 动态光影 + 角色差分 Juice"的分层动态演出。
> 依据：当前工程已有 `ProceduralBackground`、`london_background.tscn`、`gas_lamp_glow.gd`、角色 `PortraitLibrary` mood 差分等基础设施。
> 状态：方案设计阶段；其中 Tier 1（清晰度急救 + Juice 层）可立即落地，Tier 2（要素化组合场景）需先确认风格与拆分量表。

---

## 一、现状诊断

### 1.1 背景"不清晰"的根因

| 文件 | 分辨率 | 大小 | 使用场景 | 问题 |
|------|--------|------|----------|------|
| `assets/scenes/sc_01_lab.jpg` | 512×288 | 17 KB | scene1 静态背景 | 占位图，拉伸后严重模糊 |
| `assets/scenes/sc_03_indoor.jpg` | 512×288 | 6 KB | scene3 静态背景 | 占位图 |
| `assets/scenes/sc_03_indoor_hd.jpg` | 1920×1080 | 555 KB | scene3 | **高清版已存在，但未被引用** |
| `assets/backgrounds/screen01-sofa01.png` | 1920×1440 | 3434 KB | scene1  sofa 背景 | 本身清晰，但 RGB 无透明通道，无法拆分 |
| `assets/backgrounds/screen01-opendoor.png` | 1024×1024 | 1339 KB | scene1 开门切图 | 清晰但无 alpha，仅能做整张贴图切换 |
| `assets/scenes/sc_05_parlor.jpg` 等 | 512×288 | 6–18 KB | scene5/6/7/8 | 均为占位图 |

**结论**："不清晰" 80% 是源图分辨率问题，不是渲染管线问题；只要先把占位图替换为 1920×1080 高清图，糊感会立刻消失。

### 1.2 动态性不足的原因

当前 `SceneFramework.setup(title, time, bg_tex, portraits)` 只吃一张 `Texture2D` 背景贴图：

- 背景 = 一张死图，无法做视差、光影、开门 tween；
- 人物 = 静态立绘切图，没有呼吸/滑入/震屏等演出；
- 氛围 = 靠整张贴图色调，无法随玩法点亮/变暗/昼夜切换。

---

## 二、核心设计思路

**把"一张背景图"理解为"场景要素清单"，把图中的门、壁炉、窗、灯、家具、人物拆成独立节点，再叠上程序化基底、着色器氛围和角色 Juice。**

这样处理后：

- 每个要素都能独立动画（门可开、灯可闪、窗帘可摇）；
- 氛围可随剧情/玩法实时切换（取证成功→房间变亮、Finale→暗角收紧）；
- 角色不需要骨骼，靠差分 + Tween 就能做到 AVG 级别的生动演出；
- 分辨率不再依赖单张大图，可以逐件控制清晰度和风格一致性。

## 三、分层架构

```text
场景节点树（替代单一 TextureRect）
├── SceneEnvironment          # 新增：组合环境根节点
│   ├── ParallaxBackground    # 远景/中景/近景分层
│   │   ├── ProceduralSky     # 可切换 Day/Dusk/Night/Foggy
│   │   ├── FarLayer          # 远景建筑/树影（最慢移动）
│   │   ├── MidLayer          # 中景街道/花园（中速移动）
│   │   └── NearLayer         # 近景门框/柱子（最快移动，可前景遮挡）
│   ├── StaticBase            # 基底贴图或高清底图（保持兼容）
│   ├── ElementsLayer         # 拆分出的真实要素精灵
│   │   ├── Fireplace         # 壁炉节点（火焰呼吸动画）
│   │   ├── Door              # 门节点（可 tween 旋转/缩放开门）
│   │   ├── Lamp              # 灯具节点（煤气灯闪烁/绿罩台灯）
│   │   ├── Curtains          # 窗帘节点（UV 摇曳 shader）
│   │   ├── Rug / Mirror / Painting / Bookcase / Table / Chair
│   │   └── 其他剧情交互物件
│   ├── AtmosphereLayer       # 氛围层
│   │   ├── Vignette          # 暗角（Finale 收紧）
│   │   ├── Fog/Mist          # 雾气着色器
│   │   ├── DustParticles     # 浮尘粒子 GPUParticles2D
│   │   └── Rain/Snow         # 雨雪粒子（如需要）
│   └── CharacterStage        # 角色立绘层
│       ├── SpeakerSpot       # 说话人位置
│       └── NonSpeakerSpot    # 非说话人位置
```

## 四、角色演出方案（不用骨骼）

### 4.1 为什么放弃 rig

当前工程里 `sherlock/rig`、`watson/rig` 已没有实际 PNG，只剩 `.import` 空桩。2D 骨骼要出效果需要专业分层美术 + 逐顶点权重 + 关键帧动画；AI 自动切部件方案在这三项上都有先天缺陷，继续投入产出比极低。**骨架角色不是本项目的正确解法。**

### 4.2 采用方案：差分立绘 + Juice

工程里已有：

- `PortraitLibrary`：按 `speaker + mood` 取表情差分图；
- `assets/characters/watson/`：含 18+ 张差分（倾佩/兴奋/凝思/吃惊/喜悦）和姿态变体（standing/sitting/crouching/teaching）；
- `assets/characters/holmes/`：含 14 张像素表情差分。

这是《逆转裁判》《弹丸论破》等 AVG 的标准做法：人物不动关节，靠演出动。

### 4.3 具体 Juice 层

| 效果 | 实现 | 成本 | 观感提升 |
|------|------|------|----------|
| 说话呼吸 bob | Tween 循环 `position.y ± 3px` + 缩放 `1.0→1.01` | 零美术 | 立刻"像活的" |
| 出场滑入 | `position.x` 从屏幕外滑入 + `Back.out` 回弹 | 零美术 | 有仪式感 |
| 情绪爆发 | 快速缩放回弹 + 旋转 ±5° + 震屏 | 零美术 | 强化情绪 |
| 被指认/震惊 | 角色推近 + 红/白闪 + 轻微抖动 | 零美术 | 戏剧张力 |
| 镜头呼吸 | 主镜头缓慢缩放/位移 | 零美术 | 画面不死板 |
| 眨眼/嘴型 | 若美术允许，加 2–3 张眨眼差分；否则用快速 opacity 变化模拟 | 少量美术 | 更生动 |

## 五、场景动态方案

### 5.1 氛围动态（Juice 层，零美术）

| 效果 | 实现 | 触发时机 |
|------|------|----------|
| 壁炉/煤气灯闪烁 | Tween 改 `modulate` / shader 参数 | 常态循环 |
| 窗帘摇曳 | Shader UV `sin(TIME)` 偏移 | 常态循环 |
| 浮尘粒子 | `GPUParticles2D` | 有光源处 |
| 窗外雨雪 | `GPUParticles2D` + 远景暗角 | 天气场景 |
| 昼夜切换 | `ProceduralBackground.set_time_of_day()` | 剧情/时间推进 |
| 取证点亮 | Tween 整体亮度 `1.0→1.15` + 局部 lamp 变亮 | 收集关键线索后 |
| Finale 暗角 | Tween vignette 强度 `0.3→0.7` | 关键推理/对峙 |

### 5.2 物件独立动画（需拆分要素）

| 物件 | 动画方式 | 剧情/玩法联动 |
|------|----------|---------------|
| 门 | `AnimationPlayer` 旋转/缩放开门 | 进入新区域 |
| 抽屉/柜子 | Tween 位移/旋转 | 搜证成功 |
| 窗帘 | Shader 摇曳 + 风吹幅度参数 | 窗外天气 |
| 火焰/烛火 | Sprite 帧动画或 shader 扭曲 | 常态 |
| 烟雾/茶气 | `GPUParticles2D` | 常态/事件 |
| 镜子 | 反射 shader 或简单光泽 tween | 细节点缀 |

### 5.3 视差分层

把远景、中景、近景拆成独立图层，按不同速度随镜头/鼠标轻微移动：

- 远景：0.1× 位移
- 中景：0.3× 位移
- 近景：0.6× 位移
- 前景遮挡：0.9× 位移（门框、柱子）

`sc02_facade`、`sc02_path`、`sc02_street` 已经按远/中/近分好层，可直接接视差。

## 六、落地路径（分三档）

### Tier 1：清晰度急救 + Juice（1–2 天，零美术风险）

1. 接上 `sc_03_indoor_hd.jpg` 等已有高清图；
2. 对 512×288 占位场景统一重渲到 1920×1080；
3. 给当前所有角色对话加呼吸 bob + 出场滑入；
4. 给有光源的场景加 `gas_lamp_glow` 闪烁 + 浮尘粒子；
5. 清理已废弃的 rig 空桩和孤儿 `.import`。

### Tier 2：组合环境试点（3–5 天，聚焦 scene1）

以贝克街会客厅为试点：

1. 输出 scene1 要素清单（壁炉、门、窗、沙发、地毯、书架、灯、窗帘、挂画、镜子）；
2. 生成/拆分每个要素的透明 PNG；
3. 新建 `scene1_environment.tscn`：ProceduralSky 基底 + 要素精灵 + 氛围层；
4. 实现门开动画、壁炉呼吸、窗帘摇曳、取证点亮；
5. 在 `SceneFramework` 里加 `scene_environment()` 钩子，非 null 时挂环境节点替代单图。

### Tier 3：全场景铺开 + 玩法联动（在 Tier 2 验证后）

1. 将 scene2–8 按同样方式迁移；
2. 关键线索收集后触发局部动态反馈（灯亮、抽屉开、窗外变天）；
3. Finale/对峙场景做暗角 + 震屏 + 角色推近。

## 八、关于 scene1 拆分图（`场景01 拆分.png`）的评估

### 8.1 图的内容

图中包含 11 个独立像素风家具要素：

- 壁炉（带烛台/炉架）
- 铺桌布的餐桌
- 木椅
- 高书柜
- 床头柜 + 绿色台灯
- 小书柜
- 花纹窗帘（一对）
- 金色边框镜子
- 风景画框
- 红色波斯地毯
- 黄铜烛台
- 绿色台灯（另一角度）

**优点**：

1. 已透明底（棋盘格背景），可直接拖入 Godot 当 `Sprite2D`；
2. 像素风格统一，单件清晰；
3. 要素完整，覆盖了 scene1 会客厅所需的大部分家具；
4. 与方案中"拆分真实要素"的目标完全吻合。

**风险点**：

1. **风格不匹配当前 scene1 背景**：当前 `screen01-sofa01.png` 是 1920×1440 的写实/厚涂风格，而拆分图是像素风。直接拼贴会出现强烈风格割裂。
2. **缺少关键 scene1 元素**：图中没有 scene1 里明显出现的沙发、壁炉上方的装饰、华生/福尔摩斯的座椅等，需要补充。
3. **没有给出坐标/比例**：需要按 1920×1080 基准重新缩放和定位。

### 8.2 使用建议

| 方案 | 做法 | 成本 | 效果 |
|------|------|------|------|
| A. 直接用 | 把图中 11 件家具导入，拼到现有 sofa 背景上 | 最低 | **风险高**：风格割裂，像廉价贴图 |
| B. 统一成像素风 | 以拆分图为风格基准，把 `screen01-sofa01` 也重渲成同风格像素场景基底 | 中等 | 风格统一，整体变像素 AVG，协调 |
| C. 重写实风要素 | 以拆分图为"要素清单"，按现有 `screen01-sofa01` 风格重新生成/抠取写实/厚涂要素 | 中等 | 与现有背景无缝融合，效果最好 |
| **推荐** | **C 方案**：拆分图作为"拆什么"的参考清单，而非直接美术资源 | — | 风格一致 + 要素完整 |

**结论**：这张图**非常有用，但不是作为直接贴图用，而是作为 scene1 要素化拆分的"蓝图"**。它明确告诉我们贝克街会客厅应该有哪些可动物件、每个物件长什么样、比例关系如何。真正落地时，建议按图中清单重新生成与当前场景风格一致的要素。

## 九、下一步建议

1. **先确认风格方向**：是否愿意为 scene1 统一重渲一套要素？还是只想做 Tier 1 的清晰度急救 + Juice？
2. **若走要素化**：以拆分图为清单，生成 scene1 全要素透明 PNG（风格与 `screen01-sofa01` 一致），我同步在 Godot 里建 `scene1_environment.tscn` 并接好动画。
3. **若先救急**：只做 Tier 1，当天即可在 8081 看到"清晰 + 动起来"的效果。

推荐先做 **Tier 1 + scene1 要素化试点**，原因：

- Tier 1 零美术风险，当天见效；
- scene1 素材最全（高清底图、门图、角色差分最多），是最佳试验田；
- 试点成功后再决定是否铺开，避免像 rig 那样一次性高投入。
