## 2. 复用架构（核心原则：单一机制，禁止平行实现）

- **场景壳**：scene4–8 的 `.gd` 继承 `DetectiveScene`，只覆盖内容钩子（`scene_id / scene_title / hotspots / reasoning_hypothesis / map_locations / casebook_steps / 阶段流`）。
- **线索单一真相源**：`ClueSystem.collect_clue_from_catalog(id, name, desc, correct, source)`。observer 路径已用；对话路径补上后**也走它**——两套获取面，一个漏斗。
- **推理墙**：基类 `_open_wall(source, hypothesis, on_verify)` 统一入口，scene4–8 传各自 `hypothesis`。
- **存读档**：基类 `_do_save/_do_load` + `SaveSystem` 已场景无关，scene4–8 自动获得（无需新代码）。
- **对话引擎**：基类 `_start_dialogue / _make_nodes`；scene4–8 可直接 `load` 现有 tres，或**内联构造** NPC 对话（同 scene1 的 `_dn()`）——推荐内联，便于挂线索授予。
- **P2 系统自动接入**：场景完成时 `SystemEventBus.case_completed` → EndingSystem / BadgeSystem / ProgressSystem 已监听，scene4–8 只需在「场景完成」时 emit 该信号即可。

## 3. 新增机制：对话驱动线索收集（补桩，不破坏单一机制）

### 3.1 扩展数据节点
`resources/dialogues/dialogue_node_resource.gd` 增加字段：
```gdscript
@export var grants_clues: Array[String] = []   # 进入该节点时自动收集的线索 id（C_SOTCB_xxx）
```

### 3.2 补 DialogueManager 收集闭环
`dialogue_manager.gd` 的 `trigger=="clue"` 分支（现 line 246–247 仅 emit node_id）改为：
```gdscript
"clue":
    for cid in node.grants_clues:
        if ClueSystem:
            ClueSystem.collect_clue_from_catalog(cid, "", "", true, dialogue_resource.scene_id)
    # 保持事后通知语义：ClueSystem.collect_clue_from_catalog 内部已 emit clue_discovered
```
- 这样对话路径与 observer 路径**共用同一漏斗**（`collect_clue_from_catalog`），目录优先取 name/desc，幂等（`correct` 不覆盖），与 P1-3 收口一致。
- 不滥用 `clue_discovered` 当「指令」信号（它是事后广播，ProgressSystem 已监听做进度率）。

### 3.3 scene4–8 如何挂线索
- **方案 A（推荐，P3 落地）**：scene4–8 的 NPC 对话**内联构造**（同 scene1 `_dn()`），相关节点 `trigger="clue"` + `grants_clues=[...]`。不依赖编辑 tres，最快可玩。
- **方案 B（数据驱动增强，后续）**：直接给 `scene_04..08.tres` 的相关节点补 `grants_clues` 字段 → 须同步 bump **backend tres 解析器**与**对话编辑器 UI**（否则会像旧 P3 报告那样破坏往返）。P3 不建议走这条，避免引入新破损面。
- **观察/工具类线索**（scene7 尸体 701/702、窗户 703、电报 706；scene8 衣领 802）仍走 `ClueObserver` 热点（同 scene1–3），复用基类 `_create_observers`。

## 5. P2 系统接入点（scene4–8 只需 emit，无需重写）

- **ProgressSystem**：每幕注册为 case 节点，完成时 `complete_node`（或经 `case_completed` 钩子）。
- **TimelineSystem**：每幕加叙事里程碑（抵达 / 关键线索 / 推理完成），纯氛围层。
- **KnowledgeBaseSystem**：scene4–8 触发知识域（马车夫 / 盐湖城 / 共济会等），现有 7 域 + seed 可扩。
- **EndingSystem / BadgeSystem**：scene8 完成 `case_completed` → 按总星级占比评结局档位 + 徽章。
- **ToolSystem**：scene5 解锁 `TOOL_YELLOW_BOOK`；scene7 药丸验证走 tool×item 组合发现（若 seed 已定义）。
