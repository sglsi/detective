# 《谁是大侦探》音乐素材生成需求清单

> 版本：v1.0 ｜ 用途：**交由外部 AI 音乐工具（Suno / Udio / Mureka / 海绵音乐等）生成素材**
> 上游设计：见《游戏音乐设计方案.md》（音乐总监视角的系统架构与自适应状态机）
> 本文档定位：把设计方案翻译成**一份份可直接粘贴执行的生成任务单**
> 案件原型：《血字的研究》德雷伯谋杀案 ｜ 时代：维多利亚伦敦

---

## 零、使用前必读

### 0.1 三条铁律

1. **纯器乐、无人声。** 所有素材必须是 instrumental，任何哼唱、人声采样都会出戏且带来版权风险。
2. **不要现代鼓组与电子音色。** 禁用电鼓、808、EDM synth lead、电子 pad。打击乐只允许原声（钟、定音鼓、木质敲击、三角铁）。
3. **悬疑来自"未知"，不是"惊吓"。** 本游戏核心是观察→收集→推理的智力闭环，音乐要维持专注而非制造焦虑。避免突兀的 jump scare 式重音。

### 0.2 统一声音身份（Sonic Identity）

| 维度 | 定位 |
|---|---|
| 流派 | 室内乐悬疑 / 新古典（Chamber Neo-Classical Mystery） |
| 核心编制 | 独奏小提琴、中提琴、大提琴、低音提琴、毡化钢琴（felt piano）、竖琴、钟琴 |
| 色彩乐器 | 音乐盒、手摇风琴、古钢琴（fortepiano）少量点缀 |
| 打击 | 钟摆/怀表滴答、木质敲击、定音鼓、远雷、三角铁 |
| 调性倾向 | 小调为主（D 小调、A 小调、E 小调），半音化行进；真相时刻转同名大调"破雾" |
| 参考气质 | BBC《神探夏洛克》小提琴动机、《Enola Holmes》、雷顿教授的解谜古典、Ace Attorney 的张力爵士（仅取其张力感，不用爵士编制） |

### 0.3 通用 Prompt 模板

每首曲子的英文 prompt 已按此结构写好，**可直接整段复制**。结构为：

```
[风格流派], [主奏乐器 + 织体], [节奏/律动特征], [环境纹理], [调性], [BPM],
[时长], seamless loop, instrumental only, no vocals, no drums, no synth,
[情绪与画面描述], [动态要求]
```

**通用负向提示词**（各工具填到 "Exclude styles / 排除风格" 栏）：

```
vocals, lyrics, choir, rap, EDM, dubstep, trap, 808, drum machine, synth lead,
electric guitar, distortion, heavy percussion, trailer hits, epic orchestral tutti,
lo-fi hip hop, modern pop, brass fanfare
```

### 0.4 交付规格（生成后必须处理）

| 项目 | 要求 |
|---|---|
| 主格式 | **OGG Vorbis**（Godot 原生，体积极小）；WAV 亦可（会由引擎重导入） |
| 采样率 | 44.1 kHz 或 48 kHz |
| 位深 | 16 bit（WAV）/ 160 kbps（OGG，BGM）、192 kbps（stinger） |
| 响度 | 集成 −14 LUFS，true peak ≤ −1.0 dBTP |
| 循环 | **必须无缝**：首尾采样值连续，不能有爆音、不能有静音间隙 |
| 时长 | 场景 BGM 60–120 秒（AI 通常生成 2–4 分钟，需**截取**最合适的一段做循环） |
| 命名 | 见 0.5 |

> ⚠️ **关于循环的实际操作**：AI 工具几乎都做不出真正无缝的循环。做法是——生成后挑出情绪最平稳的 60–120 秒，在音频软件里做 **2–4 秒交叉淡化（crossfade）** 收尾接开头，或直接淡出/淡入 1 秒（游戏里 BGM 本身有 1.5 秒淡入淡出，短淡可接受）。

### 0.5 文件命名与落位

生成后按此命名，直接覆盖项目里的占位文件即可：

```
godot_project/assets/audio/bgm/    menu.ogg  scene1.ogg ... scene8.ogg
                                   wall.ogg  settlement.ogg  difficulty.ogg  clue_log.ogg
godot_project/assets/audio/sfx/    clue_found.ogg  wall_conflict.ogg  reveal.ogg
                                   wall_open.ogg  wall_link_ok.ogg  shock.ogg
                                   star_up.ogg  star_down.ogg
                                   ui_click.ogg  ui_hover.ogg  ui_back.ogg  ui_confirm.ogg
godot_project/assets/audio/ambience/  fog_london.ogg  gaslamp_hum.ogg
                                      carriage_distant.ogg  rain_window.ogg  fireplace.ogg
```

> 当前项目里这些位置已有**程序生成的占位音**（`tools/gen_placeholder_audio.py` 产出），同名覆盖即可，无需改代码。

## 一、场景背景音乐（9 首）

> 每首给：剧情背景 → 情绪曲线 → 编制要求 → 参数 → **可直接粘贴的 prompt**

### 1.1 MENU — 主菜单 / 案件主界面

**剧情背景**：游戏入口，221B 贝克街的地址铭牌，玩家尚未介入案件。
**情绪曲线**：优雅、邀请感、大量留白。像"有人正在壁炉旁等你坐下"。不能太悲伤，也不能太激昂——它是**门槛**而非**宣言**。
**编制**：毡化钢琴独奏开场，中提琴温暖副旋律，低音提琴极轻铺底。中段可加入独奏小提琴的一句福尔摩斯动机（极轻、若隐若现）。
**参数**：D 小调 → 中段短暂转 F 大调再回小调 ｜ 66–72 BPM ｜ 90–120 秒循环 ｜ 动态范围小（背景感强）

**Prompt（英文）**

```
Chamber neo-classical mystery theme, felt piano solo with warm viola countermelody,
soft contrabass pedal, a faint solo violin motif drifting in and out,
D minor briefly opening to F major then returning, 68 BPM, 110 seconds,
seamless loop, instrumental only, no vocals, no drums, no synth,
elegant and inviting with spacious silence, Victorian London drawing room at dusk,
restrained dynamics, background underscore, film score quality
```

### 1.2 SCENE 1 — 教学关（华生 / 信使推理墙）

**剧情背景**：华生引导玩家熟悉观察与推理墙操作，气氛安全、有导师在场。
**情绪曲线**：温暖引导 → 轻度好奇。**全程低紧张**，要给玩家"学得会"的安全感。
**编制**：中提琴主导（华生动机），钢琴分解和弦，竖琴轻拨。避免任何不谐和音。
**参数**：C 大调 / A 小调交替（明亮但不轻浮）｜ 76 BPM ｜ 90 秒循环 ｜ 中高频明亮

**Prompt（英文）**

```
Gentle chamber underscore, warm viola lead with gentle piano arpeggios and light harp
plucks, soft pizzicato pulse, C major drifting to A minor and back, 76 BPM,
90 seconds, seamless loop, instrumental only, no vocals, no drums, no synth,
mentoring and reassuring, curious but safe, a tutor standing beside you,
Victorian study room daylight, warm midrange, film score
```

### 1.3 SCENE 2 — 劳瑞斯顿花园街 3号（室外凶案现场）｜ DAY 1 上午 11:15

**剧情背景**：空宅外的花园街，雾气未散，警方尚未抵达，玩家第一次接触命案现场的外围。
**情绪曲线**：平静 → 好奇 → 隐隐不安。是**发现之前**的悬疑，不是发现之后的冲击。
**编制**：伦敦雾环境纹理（风声、远处汽笛）为底，低音提琴长音，钟琴零星点缀，钢琴稀疏单音。
**参数**：D 小调 ｜ 60–66 BPM（慢）｜ 100 秒循环 ｜ 低频厚、高频暗（雾感=低通）

**Prompt（英文）**

```
Slow atmospheric mystery underscore, low sustained contrabass drone, sparse felt piano
single notes, distant glockenspiel, faint foghorn and wind texture,
D minor, 62 BPM, 100 seconds, seamless loop, instrumental only, no vocals,
no drums, no synth, foggy Victorian London street at morning, an empty house watched
from outside, quiet dread and curiosity, dark muted highs, film score
```

### 1.4 SCENE 3 — 劳瑞斯顿花园街 3号·室内（尸体发现）｜ DAY 1 正午 12:05

**剧情背景**：进入空宅室内，发现德雷伯尸体，墙上血字 RACHE。全案第一个情绪高点。
**情绪曲线**：紧张持续爬升 → 冲击（发现尸体）→ 余震。**这是全曲张力最高的场景之一**。
**编制**：大提琴不祥半音下行（血字动机），弦乐 tremolo，定音鼓低滚奏，钟琴冷色。中段需有明显的紧张积累段（可用上行 ostinato）。
**参数**：E 小调 / 半音化 ｜ 72→88 BPM（可变速或做成两段）｜ 110 秒循环

**Prompt（英文）**

```
Dark chamber suspense cue, cello chromatic descending motif, tremolo strings,
low timpani roll, cold glockenspiel, rising ostinato building dread,
E minor with chromatic tension, 80 BPM, 110 seconds, instrumental only,
no vocals, no synth, no drum machine, discovering a murder scene in a Victorian
empty house, dread and shock, blood-red atmosphere, cinematic film score
```

### 1.5 SCENE 4 — 奥德利大院 四十六号（追查戒指线索）｜ DAY 1 下午

**剧情背景**：追查现场遗留的婚戒，走访调查，福尔摩斯的推理开始连点成线。
**情绪曲线**：好奇 → 紧张。**智性推进感**强于恐惧感——要有"在破案"的节奏感。
**编制**：拨弦脉冲（pizzicato）做律动骨架，独奏小提琴动机（福尔摩斯），钢琴点缀，低音提琴行走低音。
**参数**：A 小调 ｜ 84–92 BPM（相对偏快，体现推进）｜ 100 秒循环

**Prompt（英文）**

```
Investigative chamber underscore, pizzicato strings pulse with walking contrabass,
solo violin detective motif over top, light piano accents, subtle clock ticking,
A minor, 88 BPM, 100 seconds, seamless loop, instrumental only, no vocals,
no drums, no synth, deductive reasoning in progress, clues connecting,
alert and methodical, Victorian London afternoon, film score
```

### 1.6 SCENE 5 — 贝克街 221B 会客厅｜ DAY 1 晚 20:00–21:00

**剧情背景**：回到自己的地盘，壁炉、烟斗、推理墙。玩家整理线索、构建逻辑链。**智性主场**。
**情绪曲线**：舒适 → 专注。温暖但需要"思考空间"，不能有太多旋律干扰（会抢注意力）。
**编制**：钢琴 + 中提琴 + 竖琴，织体稀疏，留白多。可加入极轻的怀表滴答（B 律动层）。
**参数**：F 大调 / D 小调交替 ｜ 70 BPM ｜ 120 秒循环 ｜ 动态最平稳的一首

**Prompt（英文）**

```
Contemplative chamber piece, felt piano with viola and gentle harp, very sparse
texture with lots of space, faint pocket watch ticking underneath,
F major and D minor alternating, 70 BPM, 120 seconds, seamless loop,
instrumental only, no vocals, no drums, no synth, cozy Victorian parlor at night,
fireplace warmth, deep concentration, thinking music, minimal and unobtrusive
```

### 1.7 SCENE 6 — 卡彭蒂耶公寓｜ DAY 2 上午

**剧情背景**：探访与受害者过去相关的私人空间，触及情感层面（婚约、背叛、往事）。
**情绪曲线**：平静 → 好奇 → **温情回落**（含一丝哀伤）。全曲最接近"人物内心"的一首。
**编制**：独奏大提琴 + 钢琴（近似室内奏鸣曲），中后段加入中提琴温暖三度（华生动机）。避免打击乐。
**参数**：G 小调 → 降 B 大调（温情段）｜ 64 BPM ｜ 100 秒循环

**Prompt（英文）**

```
Tender chamber elegy, solo cello with intimate piano, later joined by warm viola,
no percussion, G minor opening to Bb major for a bittersweet warm section,
64 BPM, 100 seconds, seamless loop, instrumental only, no vocals, no drums,
no synth, a private apartment holding memories of a broken engagement,
melancholy but gentle, human and compassionate, film score
```

### 1.8 SCENE 7 — 郝黎代旅馆｜ DAY 2 深夜

**剧情背景**：深夜追踪嫌疑人踪迹，逼近真相。危险感第一次真正浮现。
**情绪曲线**：紧张 → 危机（dread）。低频压迫、空间感封闭（旅馆走廊）。
**编制**：低音提琴颤音 + 大提琴长音（真凶动机的隐现版），弦乐不谐和 ostinato，远处钟声，极轻的高频泛音（不安感）。
**参数**：升 F 小调 / 半音化 ｜ 76 BPM ｜ 110 秒循环 ｜ 低频加重、高频收紧（低通滤波感）

**Prompt（英文）**

```
Late-night suspense cue, contrabass tremolo and sustained low cello,
dissonant string ostinato, distant bell tolls, faint high harmonic shimmer,
F# minor with chromatic unease, 76 BPM, 110 seconds, seamless loop,
instrumental only, no vocals, no synth, no drum machine,
stalking a suspect through a dark Victorian hotel corridor at midnight,
oppressive low end, muffled highs, danger closing in, film score
```

### 1.9 SCENE 8 — 贝克街 221B 起居室·终局

**剧情背景**：真相大白，指认真凶，动机（复仇与悲悯）揭晓，案件收束。
**情绪曲线**：紧张 → **揭晓（REVEAL）** → 悲悯 → 收束。全案情绪总爆发再落地。
**编制**：先以张力层进入，揭晓时全奏（小提琴动机 + 大提琴真凶动机交织），随后大调转段（悲悯），最后钢琴独奏收尾。这首需要**内部结构变化**，是唯一一首不适合纯循环的曲子——建议做两段：`scene8.ogg`（揭晓前，可循环）+ `scene8_resolve.ogg`（收束，30–45 秒，不循环）。
**参数**：D 小调 → **D 大调**（破雾）｜ 72→96→72 BPM ｜ 90 秒 + 45 秒

**Prompt A（scene8.ogg 揭晓前，循环）**

```
Tense chamber climax builder, cello revenge motif against solo violin detective
theme interweaving, timpani, rising strings, D minor, 84 BPM, 90 seconds,
instrumental only, no vocals, no synth, no drum machine,
the moment before truth is revealed, all themes converging, film score
```

**Prompt B（scene8_resolve.ogg 收束，不循环）**

```
Resolution cue, D minor resolving triumphantly into D major, solo violin and cello
in bittersweet unison then piano alone, 72 BPM, 45 seconds,
instrumental only, no vocals, no drums, no synth,
truth revealed with compassion, the case closes, warm fading outro, film score
```

## 二、流程节点音乐（4 首）

### 2.1 WALL — 推理墙 / 思维殿堂

**触发**：打开推理墙界面（连线、建立关系）。
**气质**：水晶般澄澈、智性升腾。像"进入自己的大脑"。这是玩家停留时间较长的界面，需要**极低干扰度**。
**编制**：竖琴泛音 + 钢琴高音区 + 极轻弦乐泛音，可加细微的电子"思维脉冲"（仅限极轻的正弦脉冲，不要 synth lead）。
**参数**：A 小调 / 利底亚色彩 ｜ 68 BPM ｜ 90 秒循环

```
Crystalline chamber underscore, harp harmonics, high-register piano, faint string
overtones, gentle sine pulses like thought forming, A minor with lydian color,
68 BPM, 90 seconds, seamless loop, instrumental only, no vocals, no drums,
no synth lead, entering a mind palace, lucid and elevated, spacious, film score
```

### 2.2 SETTLEMENT — 案件结算 / 星级评定

**触发**：场景完成后的评价结算界面。
**气质**：成果兑现，温暖而有分量。不需要狂喜，是"做得不错"的肯定。
**编制**：弦乐温暖和声 + 钢琴 + 竖琴上行，尾部留余韵。
**参数**：C 大调 ｜ 80 BPM ｜ 40–60 秒（不循环或循环均可）

```
Warm achievement cue, string ensemble with piano and ascending harp, gentle swell,
C major, 80 BPM, 50 seconds, instrumental only, no vocals, no drums, no synth,
accomplishment and relief, a case well reasoned, dignified not triumphant, film score
```

### 2.3 DIFFICULTY — 难度选择

**气质**：中性、略带抉择的重量感，短。
**参数**：D 小调 ｜ 72 BPM ｜ 40 秒循环

```
Neutral anticipatory underscore, low piano chords with sustained strings,
a sense of weighing a decision, D minor, 72 BPM, 40 seconds, seamless loop,
instrumental only, no vocals, no drums, no synth, restrained, film score
```

### 2.4 CLUE_LOG — 线索记录与分析

**气质**：整理感、平稳、微律动（像翻动卷宗）。
**参数**：A 小调 ｜ 80 BPM ｜ 70 秒循环

```
Organizing underscore, pizzicato pulse with light piano and soft strings,
paper-turning rhythm, A minor, 80 BPM, 70 seconds, seamless loop,
instrumental only, no vocals, no drums, no synth, orderly and calm, film score
```

## 三、角色主导动机（Leitmotif）— 5 条

> 这些是**短动机**（8–20 秒），供对话中出现对应角色/概念时叠加播放。也可作为生成完整曲子时的"主题素材"交给工具。

| ID | 角色 | 音色 | 音型特征 | 情绪 |
|---|---|---|---|---|
| MOTIF_SHERLOCK | 福尔摩斯 | 独奏小提琴 | 小调上行跳进（小三度 + 纯五度），附点节奏 | 智性、跳跃、敏锐 |
| MOTIF_WATSON | 华生 | 中提琴 | 温暖三度伴行，级进为主 | 陪伴、叙事、可靠 |
| MOTIF_RACHE | 血字 / 受害者德雷伯 | 低音弦 + 钟琴 | 不祥半音下行 | 死亡、未解的恨 |
| MOTIF_CULPRIT | 真凶（复仇） | 大提琴长音 + 不协和下二度 | 压抑隐忍，揭示时转悲悯 | 悲剧性 |
| MOTIF_LONDON | 伦敦雾 | 风声 + 远处汽笛 + 极低的弦乐 | 城市纹理 | 环境母题 |

**生成方式**：若工具支持"以旋律为条件生成"，可用上面的音型描述作为 prompt；否则可直接生成短 cue，命名 `motif_sherlock.ogg` 等，长度 12–20 秒。

**Prompt 示例（福尔摩斯动机）**

```
Short solo violin motif, D minor ascending leap of minor third then perfect fifth,
dotted rhythm, 8 seconds, instrumental only, no accompaniment, no drums, no synth,
brilliant and analytical, a detective's signature theme
```

## 四、事件 Stinger（8 条，1–3 秒）

> 触发式短音，要求**起音明确、收尾干净**，能盖在其他声音之上而不浑浊。

| ID | 触发时机 | 听感要求 | 时长 |
|---|---|---|---|
| CLUE_FOUND | 收集到一条线索 | 轻"啊哈"：拨弦上行 + 铃音，明亮不刺耳 | 0.8–1.2 s |
| WALL_OPEN | 进入推理墙 | 竖琴上行泛音，"思维殿堂"入场 | 1.5–2.5 s |
| WALL_LINK_OK | 推理墙连线成立 | 确认感：五度跳进，温暖肯定 | 0.8–1.2 s |
| WALL_CONFLICT | 推理矛盾 / 判断错误 | 低沉警示：半音撞音，闷不刺 | 1.0–1.5 s |
| REVEAL | 真相大白 | 全奏揭示，动机交织爆发后留余韵 | 2.5–3.5 s |
| SHOCK | 惊吓 / 危机 | 急促弦乐 glissando + 定音鼓 | 1.5–2.0 s |
| STAR_UP | 结算星级上升 | 上行琶音，变现式明亮 | 1.0–1.5 s |
| STAR_DOWN | 结算星级下降 | 下行小二度，轻微失落不刻薄 | 1.0–1.5 s |

**Prompt 示例（CLUE_FOUND）**

```
Short UI stinger, harp and glockenspiel ascending flourish with pizzicato,
bright but soft, 1 second, instrumental only, no drums, no synth,
the satisfying click of realizing something, clean attack and quick decay
```

**Prompt 示例（WALL_CONFLICT）**

```
Short error stinger, low muted strings with semitone clash, dark and hollow,
1.2 seconds, instrumental only, no drums, no synth, no harsh highs,
contradiction detected, disappointing but not punishing
```

## 五、UI 音效（4 条，极短）

| ID | 用途 | 要求 | 时长 |
|---|---|---|---|
| UI_CLICK | 按钮点击 | 清脆、木质感，不要电子"哔" | 40–80 ms |
| UI_HOVER | 按钮悬停 | 极轻高频 tick，音量要低（频繁触发） | 20–40 ms |
| UI_BACK | 返回 / 关闭面板 | 下行两音，柔和 | 150–250 ms |
| UI_CONFIRM | 确认 / 提交 | 上行两音 + 轻微铃感 | 200–300 ms |

> 提示：UI 音效用 AI 音乐工具生成往往不理想，**建议用音频软件合成或取自音效库**（Bandcamp-free SFX、Freesound CC0）。若坚持 AI 生成，用"short UI sound effect, wooden click"类 prompt 并大幅降音量。

## 六、环境音 Ambience（5 条，可循环）

> 路由到 `Ambience` 总线，与 BGM 叠加，音量压得很低（作为空间感）。

| ID | 内容 | 要求 |
|---|---|---|
| AMB_FOG_LONDON | 伦敦雾 / 远处城市底噪 | 低频风声 + 模糊城市噪底，30–60 s 循环 |
| AMB_GASLAMP | 煤气灯嘶嘶声 | 极轻的高频嘶声 + 火苗抖动，用于室外夜景 |
| AMB_CARRIAGE | 远处马车 | 偶发的马蹄与车轮声（不要规律循环，避免机械感） |
| AMB_RAIN_WINDOW | 窗上雨声 | 中等雨量，室内视角，闷一点 |
| AMB_FIREPLACE | 壁炉 | 火焰噼啪，用于贝克街 221B |

> 环境音**强烈建议从音效库取**（Freesound CC0 / BBC Sound Effects），AI 生成的环境音往往有明显 artifacts。

## 七、交付验收清单

生成完按此逐条核对：

- [ ] 全部为 **instrumental，无人声**
- [ ] 无电子鼓组、无 synth lead、无现代流行元素
- [ ] 格式 OGG（或 WAV），44.1/48 kHz，响度一致（−14 LUFS，peak ≤ −1 dBTP）
- [ ] 9 首场景 BGM + 4 首流程曲，命名与 0.5 一致
- [ ] 每首**循环无缝**（首尾无爆音、无静音间隙），时长 60–120 秒
- [ ] 8 条 stinger 起音干净、长度符合表格
- [ ] 各曲之间有**统一音色感**（同一套乐器/同一混响空间），不要像拼盘
- [ ] 场景 2/3/7 的低频不会在笔记本小喇叭上糊掉（需在手机/笔记本外放上试听）

### 替换到项目的步骤

1. 把文件按 0.5 的命名放进 `godot_project/assets/audio/` 对应目录（同名覆盖占位文件）
2. 若是 OGG，需同步删除或替换同名 `.import` 文件（Godot 重新导入时会自动生成）
3. 重跑 Web 导出：`--export-release "Web" web_build/index.html`，再跑 `tools/inject_pck_version.py <时间戳>`
4. 浏览器硬刷验证

### 关于"分层（4-stem）"的说明

设计方案里的 A/B/C/D 四层实时混音（M2 阶段功能）**无法由 AI 工具一步生成**。两种路径：

- **实用路径（推荐）**：先按本文档生成完整混音曲跑通 M1；后续用 stem 分离工具（Moises / UVR / LALAL.ai）把每首拆成 4 轨，人工整理成 A 基底 / B 律动 / C 旋律 / D 张力。
- **直接路径**：分 4 次生成，每次只写一种织体（如 "only sustained pad and bass, no melody, no percussion"），**必须指定相同 BPM 与调性**才能对齐。

## 八、优先级建议（若时间/额度有限）

按这个顺序生成，性价比最高：

1. **MENU**（主菜单，玩家第一印象）
2. **SCENE 2 / SCENE 3**（命案现场，情绪最高、最需要音乐支撑）
3. **WALL**（推理墙，玩家停留最久的界面）
4. **CLUE_FOUND**（触发最频繁，正反馈核心）
5. **SCENE 8 + scene8_resolve**（终局高潮）
6. 其余场景 BGM 与 stinger

占位素材已经能出声，可以先跑通流程，再逐首替换。
