# 角色与镜头电影感实现方案

> 适用范围：本侦探游戏（Godot 4.7，2D 对话/推理向）。
> 目标：让角色"活"起来、让镜头有电影感，同时控制美术与工程量。
> 状态：阶段一「立绘微动」已落地（见第五节）；阶段二~四为规划，待实施。

---

## 一、角色图像通常怎么生成

### 1.1 2D 路线（本游戏现状）

- **美术来源**：AI 生图或手绘 → 绿幕/抠底 → 透明 PNG（项目内 `watson_*.png`、`alice_bust.png`、`sherlock_spritesheet.png` 等均走此路）。
- **动画资源两种做法**：
  1. **帧动画（精灵表）**：把一整套动作（idle 8 帧 / walk 8 帧 / run 8 帧…）排进一张大图，用 `AnimatedSprite2D` 按帧播放，或 `Sprite2D` + `AnimationPlayer` 改 `frame` 属性。
  2. **骨架动画（Skeleton2D）**：把角色拆成骨头（`Bone2D`）+ 蒙皮多边形，美术只画一次分层部件，动画师转骨头即可做任意姿势——省量、能做呼吸/眨眼/嘴形等微动。
- **导出**：Godot 直接吃 PNG/精灵表；外部在 Aseprite / Krita / Live2D / Spine 做完导入即可。

### 1.2 3D 路线（对照，真电影感更顺）

- 建模（Blender）→ 绑骨架 → 蒙皮（Weight Paint）→ 做动画片段 → 导出 `.glb/.gltf`。
- Godot 内 `AnimationPlayer` / `AnimationTree` 直接吃 GLTF 动画，与 2D 同一套系统。
- 3D 的走跑跳、镜头推拉、景深虚化都更自然，但美术成本显著高于 2D。

### 1.3 本游戏资产盘点（缺口）

| 角色 | 状态 | 备注 |
|---|---|---|
| 福尔摩斯 | 像素精灵表 `sherlock_spritesheet.png`（idle/inspect/point/think/walk） | 已会动 |
| 华生 | 40+ 全身/情绪 PNG + `watson_bust.png` 半身像 | 静态，无走动动画 |
| NPC（葛莱森/雷斯垂德/爱莉丝…） | 单表情立绘 | 静态 |
| drebber / harper / team_kid | 无美术 | 真缺口，需素材 |
| 站立角色（场景内 `_portraits`） | 静态透明 PNG | 阶段一已加微动 |

> 本环境无 ImageGen 文生图能力；新素材走绿幕抠图管线（godot-asset-generator）对已有图 cutout，或待有生成能力的环境产出。

## 二、角色运动（走/跑/跳）怎么实现

核心原则：**运动逻辑与动画状态机解耦**。

1. **运动学载体**：用 `CharacterBody2D`（2D）/ `CharacterBody3D`（3D），别用 `RigidBody`（不可控会打滑）。它负责读输入 → 算速度 → `move_and_slide()` 真移动 → `is_on_floor()` 落地检测。
2. **动画状态机**：`AnimationTree` 根节点设 `AnimationNodeStateMachine`，建 `idle/walk/run/jump/fall`；用 `AnimationNodeBlendSpace2D` 按水平速度大小在 walk↔run 连续混合（速度小=走，大=跑）。
3. **参数打通**：`CharacterBody2D` 每帧把 `velocity.length()`、`is_on_floor()` 写进 `AnimationTree`：`set("parameters/.../blend_amount", ...)`，动画跟着动。
4. **根运动（root motion）**：动画本身带位移时开启，位移来自动画而非代码，避免"滑步"。
5. **跳跃**：重力每帧 `velocity.y += gravity*delta`；地面按下跳 `velocity.y = -jump_impulse`；空中可限制（二段跳可选）。

示意（仅讲解，不写入工程）：
```gdscript
# Player.gd  (CharacterBody2D 根)
@onready var anim := $AnimationTree
func _physics_process(delta):
    var dir := Input.get_axis("左","右")
    velocity.x = dir * SPEED
    velocity.y += GRAVITY * delta
    if Input.is_action_just_pressed("跳") and is_on_floor():
        velocity.y = -JUMP
    move_and_slide()
    anim.set("parameters/state_machine/playback", "walk" if dir != 0 else "idle")
    anim.set("parameters/blend/blend_amount", abs(velocity.x)/SPEED)
```

## 三、镜头：拉远接近 / 切换视角 / 电影感

- **基础**：2D 用 `Camera2D`、3D 用 `Camera3D`，同时只有一个 `current` 相机（`camera.make_current()` 切换）。
- **跟随**：`Camera2D.position_smoothing_enabled = true` + `position_smoothing_speed`，相机 lerp 平滑追目标；或手写 `global_position = lerp(global_position, target.global_position, 0.1)`。
- **拉远/接近**：改 `camera.zoom`（2D：`0.6` 拉远、`2.0` 推近），用 `Tween` / `AnimationPlayer` 对 zoom 缓动 = 电影推拉。
- **切换视角（多机位）**：
  - 做法 A：场景放多个相机（特写 A / 全景 B / 过场 C），切时 `camera_b.make_current()`——适合固定分镜（对话特写 / 现场全景）。
  - 做法 B：单相机 + 预设 `Transform` 列表，用 `Tween` 在预设间平滑过渡——更省节点，适合自由运镜。
- **电影感运镜**：
  - **dolly 轨道**：`Path3D` 画轨迹，相机挂 `PathFollow3D`，`progress` 随时间走 = 沿轨道平滑移动（走进房间 / 环绕角色）。
  - **Tween 缓动**：对 `position` / `rotation` / `zoom` 缓动，配 `ease_in_out` 曲线即有电影感。
  - **关键帧**：`AnimationPlayer` 给相机 K 帧（position / rotation / fov），播一段即一段运镜。
- **后处理（让画面像电影）**：
  - `WorldEnvironment` + `Environment`：开 **bloom**（灯光辉光）、**SSAO**（接触阴影体积感）、色调映射（胶片感）。
  - `CameraAttributesPhysical`：开 **景深 DOF**（焦点外虚化，特写人脸时背景糊 = 电影感核心）、曝光/光圈。
  - **letterbox 黑边**：`ColorRect` 上下两条黑边遮成 21:9，瞬间电影。
  - **时间感**：`Engine.time_scale = 0.3` 慢动作（顿悟 / 揭露瞬间）；`hitstop` 极短 `time_scale = 0` 做打击感。

示意（仅讲解）：
```gdscript
func play_dramatic_zoom(target):
    letterbox.show()
    var t := create_tween()
    t.tween_property(camera, "zoom", Vector2(2.2,2.2), 1.2).set_ease(Tween.EASE_IN_OUT)
    t.parallel().tween_property(camera, "global_position", target.global_position, 1.2)
    Engine.time_scale = 0.4          # 慢动作
    await t.finished
    Engine.time_scale = 1.0
```

## 四、落地计划（分阶段）

本游戏是**点击/对话推理向**，不是动作游戏，"走跑跳"未必需要。更划算的电影感投资是三层递进：

### 阶段一：立绘微动（已落地 ✅）
给对话立绘与场景站立角色加纯属性动画（呼吸缩放 + 浮动 + 微旋转），对话不呆、资源量小、观感提升大。**无需任何新美术**。

### 阶段二：调查镜头（待实施）
点线索时相机 `zoom` 缓动推近 + 轻微偏移 + 短暂 letterbox；离开拉回。即"走近看证据"的电影感，无需角色走动。

### 阶段三：过场运镜 + 后处理（待实施）
关键剧情（凶案重现、凶手揭露）用 `Path3D` / `Tween` / `AnimationPlayer` 做推拉摇移 + DOF + 黑边。

### 阶段四：角色自由走动（若需探索贝克街）
上 `CharacterBody2D + AnimationTree(StateMachine+BlendSpace2D)`，把现有 PNG 补成走/跑/跳片段（Holmes 精灵表可复用模式）。

## 五、立绘微动实现细节（已落地）

### 5.1 组件 `PortraitMicroAnimator`
- 路径：`scripts/ui/portrait_micro_animator.gd`（`class_name PortraitMicroAnimator`，`extends Node`）。
- 原理：纯属性动画，无美术依赖。
  - **呼吸**：`scale.y = 1 + sin(t·speed + phase)·amp`，且把 `pivot_offset` 设为 `size/2`，缩放绕中心、不偏移。
  - **浮动**：`position.y = home.y + sin(t·float_speed + phase)·float_amp`（说话时额外加大 `talk_bob_extra`、加快）。
  - **微旋转**：`rotation = sin(...)·sway_deg`（站立角色用，避免裁框）。
  - 每个实例随机 `phase`，避免群体同呼吸。
- 接口：
  - `setup(target: TextureRect)` —— 绑定目标并捕获 `home` 位置、随机相位。
  - `set_talking(on: bool)` —— 说话时加大浮动幅度/频率。
  - `set_home(pos: Vector2)` —— 外部改了立绘位置后刷新基准（如 `_speaker_portrait` 左下/右上切换）。
  - `enabled` / `float_enabled` / `sway_enabled` 等 `@export` 可调项。

### 5.2 接入点
- `DialogueRenderer`：`_ready` 内建 animator 并 `setup($Portrait)`；`_start_typewriter` 开始时 `set_talking(true)`、打完 `set_talking(false)`。
- `SceneFramework._speaker_portrait`：`_build_all` 建好立绘后挂 animator；`set_dialogue` 切换左下/右上位置时 `set_home(pos)`、显示时 `set_talking(true)`、隐藏时 `set_talking(false)`。
- `SceneFramework._make_portrait` 的站立角色 `img`：挂 animator，关 `float_enabled`、开 `sway_enabled`（在金框内微摆，不裁边）。

### 5.3 参数与可调项（默认值）
| 参数 | 默认 | 说明 |
|---|---|---|
| breathe_amplitude | 0.02 | 呼吸缩放幅度（scale.y） |
| breathe_speed | 1.6 | 呼吸频率 |
| float_amplitude | 4.0 | 浮动位移（px） |
| float_speed | 0.8 | 浮动频率 |
| talk_bob_extra | 6.0 | 说话时额外浮动 |
| sway_amplitude_deg | 0.6 | 微旋转幅度（度） |
| enabled / float_enabled / sway_enabled | true | 开关 |

> 调参即可整体控制"活"的程度；后续若接入 `SettingsManager` 可做用户开关。
