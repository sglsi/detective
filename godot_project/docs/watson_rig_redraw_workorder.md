# 华生（Watson）可绑骨部件 · 重画工单 v1

> **目的**：上一版（v3，2026-08-01 入库）经视觉复检**不合格**——11 张部件全部可见骨骼/骨架线（X 光透视），违反规格书 §7.1 一票否决。本工单把 11 张图整体重画，交付到 `assets/characters/watson/rig/`（覆盖原图）。
> **基准**：`docs/watson_rig_asset_spec.md` v2（本工单是其「可执行版」，数字均取自该规格书 §5 / §2 / §3.5 / §8）。
> **实测依据**：程序化检查确认 §5 比例三套候选图均精确匹配（无需改尺寸）；唯一抓实的程序化缺陷是 `upperarm_L` 近端偏左 36–44%；用户肉眼确认三套图均有 X 光/骨骼线。

---

## 0. 一句话给生图 AI 的定位

「你画的是**游戏角色正常穿衣服的外观贴图**（像《街霸》角色拆分图），**不是解剖图**。永远看不到衣服底下的骨头、肌肉、内脏。骨骼是程序运行时才挂上去的，你只管把穿好衣服的肢体画出来。」

## 5. 上一版实测两处缺陷（重画务必修掉）

1. **`upperarm_L` 近端关节偏左 ~43%**（rig / v4 / from_three_views 三套同错）
   - 程序化测得顶部质心水平偏移 36–44%，绑到骨骼时左上臂整体横移、与躯干脱节。
   - **修法**：重画时把左上臂的**肩球端强制置于画布顶边水平正中央**（其余部件已 <10% 达标，可作参照）。
2. **全部部件含 X 光 / 骨骼线**（用户肉眼确认）
   - 违反 §3.5 一票否决。严格按 §2–3 负向词执行，任何骨头、骨架、X 光、半透明衣物一律不得出现。
