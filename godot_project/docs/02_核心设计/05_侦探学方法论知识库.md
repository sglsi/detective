## 1. 背景与目标

### 1.1 为什么需要扩展

`04_推理知识库.md` 已建立 7 大主题域（KB-A~G），但其条目是**围绕具体案件（《血字的研究》）
所需背景**而设（如 KB-D 德文字体、KB-G 交通速度）。它回答"玩家破本案需要知道什么"。

本扩展要回答一个不同的问题：**"那个时代的侦探，作为一个专业群体，掌握着怎样一套方法论？"**
这套内容与具体案件解耦，可跨案件、跨场景复用，并为游戏提供"时代知识"的厚度与可信度。

### 1.2 设计目标

| 目标 | 描述 | 衡量标准 |
|------|------|----------|
| **方法论体系化** | 覆盖现场勘查、法医学、身份识别、犯罪学、警务实务五大支柱 | 5 个新域全部建立并有条目 |
| **知识真实性** | 条目内容可追溯到该时期真实著作（书名+章节） | 每条含 `source` 字段，抽检可溯源 |
| **时代性（含缺陷）** | 如实呈现当时的方法、认知与错误（如天生犯罪人、面相学） | 存在专门的"时代缺陷"条目 |
| **跨案件复用** | 不绑定任何具体案件 | 案件专属内容占比 = 0% |
| **兼容既有系统** | 复用现有 `KnowledgeBaseSystem`，不改其检索/浏览逻辑 | 现有 22 条不受影响，check-only 通过 |

### 1.3 核心原则

1. **通用 ≠ 案件库**：描述"当年侦探知道/相信什么"，而非现代正确结论。
2. **如实保留缺陷**：已被证伪的方法（人体测量、天生犯罪人、面相学、刑讯）**必须收录并标注**，
   它们是时代感与**推理陷阱**的来源。
3. **可溯源**：每条注明出处；不得写入无法考证的杜撰内容。
4. **不提供答案**：与 04 一致——提供素材，结论由玩家得出。
5. **以真实史料为据**：新条目一律基于可考的 19 世纪著作撰写，**严禁凭空编撰**；既有 KB-A~G 的定位见 §2.3。

### 2.3 关于既有 7 域 KB-A~G 的定位（重要）

既有 KB-A~G 是**以游戏叙事需要为基础**编制的（服务于《血字的研究》等具体案件所需背景），
其条目**未逐条以史料校验**，存在“为剧情服务、真实性有限”的局限。本次扩展对二者的定位如下：

| 维度 | KB-A~G（既有） | KB-H~L（本次扩展） |
|------|---------------|-------------------|
| 编制依据 | 游戏叙事需要 | **19 世纪真实著作** |
| 真实性 | 未逐条校验 | 逐条标注 `source`，可溯源 |
| 地位 | 游戏“时代背景”（保留） | 知识库**真实性主干** |
| 处理方式 | 保留；吸纳其可靠内容 | 新建；与旧条目互链 |

具体处置原则：
1. **不删**既有条目（游戏叙事仍在使用），此后**不再新增**同类“剧情化”内容；
2. 既有条目中确属真实可靠者（如 KB-B-3 足迹分析、KB-C 毒物、KB-E 证词），
   以 KB-H~L 的**真实条目重新表述并建立 `related` 互链**；
3. 后续阶段将逐步以史料**校订/替换** KB-A~G 中经不起考据的表述——但**严禁凭空杜撰**；
4. 判定某条是否“编撰”的标准：**能否在真实著作中找到依据**。找不到依据的，应改写或降级。

## 3. 内容架构：新增 5 域详解

### KB-H 侦查学总纲与现场勘查（`INVESTIGATION_SYSTEM`）

> 来源：Hans Gross《Criminal Psychology》(1898/1911)、《Criminal Investigation》(1893/1906)

| 子主题 | 拟收录条目 |
|--------|-----------|
| 侦查员素养 | 优秀侦查员应具备的品质；观察力训练；偏见与先入为主的危害 |
| 现场勘查程序 | **"未先记录，绝不移动任何物件"**；现场保护；勘查顺序；笔录规范 |
| 物证采集 | 足迹（石膏制模）、血迹形态、灰尘与微量物证、文书检视 |
| 装备与专家 | 侦查员的随身装备；何时求助法医/化学家/笔迹专家；专家证言的局限 |
| 讯问与证词心理 | 证人记忆的不可靠性；诱导性提问的风险；供述的心理学 |

**标志性条目示例**
- `KB-H-1`「现场保护的第一原则」：Gross 主张"在把任何物件的位置、状态细致记录下来之前，绝不移动、拿起、甚至触碰它"；对应当时警方常"像一群野牛般践踏现场"的现实。
- `KB-H-2`「证人证言的不可靠」：强调物证优于人证，与同期司法实践（重口供）形成张力。

### KB-I 身份识别技术（`IDENTIFICATION`）

> 来源：Bertillon《Instructions signalétiques》(1893)；Galton《Finger Prints》(1892)；Henry(1900)；Herschel / Faulds

| 子主题 | 拟收录条目 |
|--------|-----------|
| 人体测量 | 贝蒂荣法（11–12 项测量）；测量流程；**误差与淘汰**（时代局限） |
| 指纹学 | Herschel 契约指纹、Faulds 的《Nature》论文、Galton 统计模型、Henry 十分类法 |
| 罪犯档案 | 口卡与免冠照（mug shot）；"Rogues' Gallery"；现场摄影系统化 |
| 语言肖像 | Bertillon"portrait parlé"：用标准化词汇描述外貌以便检索 |

**标志性条目示例**
- `KB-I-3`「两种识别法的竞争」：人体测量因误差被指纹取代（1890s–1901）；呈现"技术演进"而非"一步到位"。

### KB-J 犯罪学理论与时代观念（`CRIMINOLOGY_THEORY`）

> 来源：Lombroso《L'uomo delinquente》(1876)；Ferri《Criminal Sociology》(1884)；Garofalo(1885)；Havelock Ellis《The Criminal》(1890)

| 子主题 | 拟收录条目 |
|--------|-----------|
| 实证犯罪学 | 龙勃罗梭的实证方法（测量、统计）；"犯罪人"作为研究对象 |
| **天生犯罪人**（时代缺陷） | 返祖说；各类"犯罪人特征"；**后世否定**（必须标注） |
| 面相与颅相（时代缺陷） | 颅相学（Gall）、面相学；"看脸识罪犯"的流行与谬误 |
| 犯罪类型学 | 生来型/激情型/精神病型/偶然型；"职业罪犯"观念 |

> ⚠️ **本域是"时代缺陷"的集中承载区**。条目须以"当时的人如何认为"的口吻撰写，
> 并明确标注 `limitation`（后世结论）。游戏中可据此生成"证人/警探误判"的推理陷阱。

### KB-K 侦探职业与警务实务（`DETECTIVE_PROFESSION`）

> 来源：Howard Vincent《A Police Code》(1881)；Byrnes《Professional Criminals of America》(1886)；Pinkerton 回忆录；Dilnot《Scotland Yard》(1915)

| 子主题 | 拟收录条目 |
|--------|-----------|
| 机构沿革 | Bow Street Runners（1748）→ 大都市警察（1829）→ CID（1878）；警衔与分工 |
| 侦探培养 | 学徒制；"制造一个侦探"（Dilnot）；警察学校；巡警的观察训练 |
| 罪犯图册与情报 | Rogues' Gallery；《警方公报》(Police Gazette)；罪犯惯用手法与黑话 |
| 私家侦探 | 平克顿事务所；跟踪、伪装、卧底；劳资纠纷中的角色 |
| **审讯手段**（时代缺陷） | "third degree"（肉体+精神逼供）；24 小时轮番审讯；**其违法性与后世禁止** |

### KB-L 法医学与尸体检验（`FORENSIC_MEDICINE`）

> 来源：A. S. Taylor《Principles and Practice of Medical Jurisprudence》(1865)；W. A. Guy(1844)；Witthaus(1894–96)；Christison(1829)

| 子主题 | 拟收录条目 |
|--------|-----------|
| 死亡与尸检 | 死亡征象；"假死"（suspended animation）；尸体现象与死亡时间估计 |
| 创伤与枪伤 | 枪伤创口判读（远/近距离）；刀伤与凶器推断；**创口特征的解读及争议** |
| 中毒与检测 | 砒霜 Marsh 试验；生物碱检测；**检测误差（Smethurst 案）** |
| 身份鉴定 | 依骨骼、牙齿、疤痕、旧伤鉴定无名尸 |
| 法医出庭 | 专家证人的地位；Partisanship 争议；"专家证言可否采信" |

## 4. 条目数据结构

### 4.1 既有字段（保持兼容，必填）

```json
{
  "id": "KB-H-1",
  "domain": "KB-H",
  "subdomain": "现场勘查程序",
  "title": "现场保护的第一原则",
  "keywords": ["现场保护", "物证", "记录"],
  "summary": "在未细致记录之前，绝不移动、拿起或触碰现场任何物件。",
  "body": "……（正文，2–6 句，含方法/案例/时代背景）",
  "related": ["KB-E-2"],
  "tags": ["侦查方法", "Gross"]
}
```

### 4.2 扩展字段（本扩展新增，建议填写）

| 字段 | 类型 | 说明 | 用途 |
|------|------|------|------|
| `era` | string | 年代/时间性，如 `"1893"` | 呈现"知识的时间性"；UI 可显示"出自 1893 年" |
| `source` | string | 出处，如 `"Hans Gross, Criminal Investigation, 1906, Pt.1 Ch.3"` | **可溯源性要求** |
| `limitation` | string | 时代局限 / 后世结论，如 `"人体测量因误差被指纹取代"` | 时代缺陷标注；困难模式矛盾信息 |
| `case_ref` | string | 关联的真实案例，如 `"Smethurst 案(1860)"` | 案例索引 |

> **系统兼容性**：现有 `KnowledgeBaseSystem` 只读取上述"既有字段"，**新增字段会被安全忽略**，
> 不会导致解析错误。M2+ 可在条目详情 UI 中展示 `source / era / limitation`。
> **阶段 1 不修改任何 .gd 逻辑，仅追加数据。**

### 4.3 命名与编号规范

- 条目 id：`KB-<域字母>-<序号>`（域内从 1 递增）。**新域的序号与既有域互不干扰**（如 KB-H-1）。
- 子主题名：沿用 04 文档的简洁中文命名（如"现场勘查程序"）。
- `keywords`：3–6 个，含**玩家可能输入的检索词**（含俗名/异名）。
- 难度差异：沿用系统规则——困难模式仅精确匹配标题+关键词，故**关键词须覆盖主要别名**。
