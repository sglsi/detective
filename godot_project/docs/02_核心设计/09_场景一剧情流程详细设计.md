## 1. 阶段 0 · 赫德森太太端茶 · 悬念开场（`MRS_HUDSON`）

**触发**：场景加载完成 → 基类 `_enter_arrival()` → `_show_mrs_hudson_dialogue()`
**演出节点**：221B 客厅大全景（瓶罐、烛光、烟雾），福尔摩斯背对镜头做实验；赫德森太太端茶盘入画。
**对话脚本**（08 L331–393 赫德森段 + L135–153 初次见面悬念）：

```
赫德森太太："福尔摩斯先生，茶来了。哦，华生医生，欢迎您。"
福尔摩斯（上下打量华生，停顿2秒，特写）："……阿富汗军医。"
华生（一愣，吃惊）："什么？"
福尔摩斯："我说，你是一名刚从阿富汗回来的军医。我说对了吗？"
华生（惊讶）："您……您怎么知道的？我们刚认识不到十秒钟。"
福尔摩斯（微笑，转向玩家视角）："这位新朋友显然不相信。不如——你来告诉他我是怎么看出来的？"
```

**玩家操作**：点击 / Enter / Space 推进对话（ DialogueManager `_dm.advance()` ）。
**难度**：全难度一致（悬念开场不作难度分叉；`easy/normal/hard_start_node` 均为 `h0`）。
**实现钩子**：`_show_mrs_hudson_dialogue()` → `_on_mrs_hudson_end()` → `_show_opening_dialogue()`
**推进**：对话结束即进入阶段 1。

## 2. 阶段 1 · 初次见面 + 系统新手教程提示（`OPENING`）

**触发**：`_on_mrs_hudson_end()` 调用 `_show_opening_dialogue()`
**对话脚本**（08 L149–152 系统提示 + L135–153 开场）：

```
福尔摩斯（从容）："证据在你身上：手腕、左臂、面色、站姿。"
系统（guide）：[新手教程] 第一次观察
  → 目标：找出 4 条线索，证明「华生是阿富汗军医」
  → 操作：点击华生身上高亮的圆圈，逐一观察细节
系统（guide）：点击华生身上高亮的圆圈。完成后进入推理墙验证。
```

**玩家操作**：点击推进；结束后自动进入华生观察阶段（阶段 2）。
**系统提示首次**：新手教程提示框（目标 + 操作指引）。
**实现钩子**：`_show_opening_dialogue()` → `_on_opening_end()`（置 `OBSERVE_WATSON`、显示华生立绘、弹观察器、弹道具工具栏）。
**推进**：对话结束 → 阶段 2。

> ⚠️ **台词库 vs 实现差异点 A**：08 L170 教程把 4 部位写作「手腕 / 左臂 / 面色 / 站姿」，但当前 `scene1.gd` 热点表把左臂写成 `shoulder`（标签「右肩损伤」），与「左臂僵硬=战场负伤」的原意略有出入。需统一为同一说法（建议以 _all_hotspots 文案为准，或回改台词库为「右肩」）。

## 3. 阶段 2 · 华生观察 · 第一次六步探索闭环（`OBSERVE_WATSON` → `WATSON_REASONING`）

### 3.1 进入与演出
- `_on_opening_end()`：华生立绘 `_portrait_ctrl.visible=true` → `_watson_obs.show()` → 自动弹道具工具栏。
- **观察器首屏**：华生教学图（`watson_teaching.png`）上 4 个部位以**圆圈高亮**（难度决定亮度/有无），进入观察即高亮（非先出文字框）。

### 3.2 六步闭环逐 Step 映射（依据 08 L155–352）

| Step | 名称 | 当前实现映射 | 玩家动作 | 反馈 |
|------|------|------------|---------|------|
| 1 | 观察发现（必做） | 圆圈高亮 + 点击部位 | 点高亮圆圈 → 弹该部位放大图（金框）+ 底部文字说明 | 08 L168–191 难度提示 |
| 2 | 工具操作（必做） | 放大镜（观察器内嵌） | 简单：系统推荐放大镜高亮；普通/困难：自选 | 08 L199–218 |
| 3 | 数据记录（必做） | 退出放大图时记入推理墙 + 侦探笔记首次弹出 | 看文字后再次点击/按键退出 → 该线索记录 | 08 L224–254 侦探笔记首弹 |
| 4 | 知识检索（可选·M2+） | 知识库入口（当前未单独弹） | 去知识库查「热带/战伤/军人姿态」 | 08 L259–273 |
| 5 | 假设形成（可选） | 推理墙（统一 _open_wall） | 拖拽两条线索建假设「活跃中」 | 08 L276–297 |
| 6 | 验证修正（必做） | `_show_watson_reasoning_wall()` | 集齐 4 → 连线提交 → 四级验证 | 08 L300–351 |

### 3.3 华生 4 条线索（热点/锚点/文案）

| id | 标签 | 锚点 | 文案（desc） | correct |
|----|------|------|------------|---------|
| `wrist` | 肤色黑白分明 | `watson_teaching.png`→`wrist` | 手腕处肤色分界明显——长期暴露于热带阳光，刚从热带归来 | ✓ |
| `shoulder` | 右肩损伤 | →`shoulder` | 右肩动作略显僵硬——战场负伤留下的旧疾 | ✓ |
| `face` | 脸部疲惫 | →`face` | 面部疲惫、面色黝黑——久病初愈、长途劳顿的痕迹 | ✓ |
| `pose` | 军人气质 | →`pose` | 站姿挺拔、气质干练——典型的军人作风 | ✓ |

### 3.4 难度差异（依据 08 L168–191 / L229–349）

| 难度 | Step1 提示 | Step2 工具 | Step3 笔记 | Step6 验证结果 |
|------|-----------|-----------|-----------|---------------|
| 简单 | 4 处依次闪烁高亮，点击下一处 | 自动推荐放大镜 | 自动填充，滑杆确认程度 | 必 VERIFIED |
| 普通 | 微光提示，不提示剩余数 | 自选，选错温和提示 | 空白模板滑杆/多选 | 4条全→VERIFIED；少→SUPPORTED/INSUFFICIENT |
| 困难 | 无提示，自由探索 | 自选，选错无反馈 | 完全空白自由记录 | 玩家自判，提交给四档 |

### 3.5 推理墙验证（`WATSON_REASONING`）
- 集齐 4 线索 → `_on_watson_all_recorded()` → `_show_watson_reasoning_wall()`。
- 假设板：W-01 肤色晒痕 / W-02 右肩旧伤 / W-03 面色憔悴 / W-04 军人站姿。
- **验证通过（VERIFIED）** → 里程碑「初识推理」点亮 + 观察之星 ⭐ + 福尔摩斯总结台词（08 L317–319）。
- **验证不足**：福尔摩斯「再回去看看？」→ 允许返回重探（不扣分）。

### 3.6 教程后对话（08 L354–393）
```
华生（敬佩）："这……太不可思议了。仅仅从这些细节，就能看出这么多？"
福尔摩斯："不错的初次表演。大多数人看到的只是表象，而侦探看到的是——历史。"
华生："系统化……听着像一门科学。"
福尔摩斯："它就是一门科学。只是大多数人不懂得运用。"
（赫德森太太端茶收尾，沉浸感）
```
**系统提示**：侦探笔记已更新 / 推理墙已开启。

### 3.7 推进
验证通过 → `_start_messenger_phase()`（信使到访）。

## 4. 阶段 3 · 信使到访 · 第二次六步闭环（`MESSENGER_OBSERVE` → `MESSENGER_REASONING`）

### 4.1 进入与演出（08 L395–417）
- 楼梯脚步声 → 门铃 → 信使推门昂首挺胸递信 → 字幕「第二次练习机会」。
- 对话：福尔摩斯瞥信使手背锚文身 → 「您曾经是海军陆战队军士吧」→ 转玩家「这次，你来试试？」
- `_start_messenger_phase()`：信使立绘显示、弹观察器、弹道具栏。

### 4.2 信使 6 观察点（4 正确 + 2 干扰；困难 + 深度干扰）

| id | 标签 | 锚点 | 文案 | correct | 类型 |
|----|------|------|------|---------|------|
| `tattoo` | 手背锚文身 | `messenger_spritesheet.png`→`tattoo` | 蓝色锚形文身→海军标志 | ✓ | 正确 |
| `beard` | 络腮胡 | →`beard` | 军人式络腮胡→军队常见 | ✓ | 正确 |
| `posture` | 挺拔站姿 | →`posture` | 昂首挺胸→军事训练 | ✓ | 正确 |
| `manner` | 神态平静/发号施令 | →`manner` | 发号施令→军士/士官 | ✓ | 正确 |
| `sleeve` | 袖口磨损 | →`sleeve` | 看似职业线索，实际衣服旧了 | ✗ | 干扰 |
| `limp` | 轻微跛行 | →`limp` | 看似负伤，实际今天脚扭了 | ✗ | 干扰 |
| （困难）药房收据 | 口袋露出半张 | — | 看似有故事，实际感冒药 | ✗ | 深度干扰（70% 概率） |

### 4.3 难度差异（依据 08 L442–480）

| 难度 | 正确/干扰呈现 | 干扰处理 | 验证判定 |
|------|--------------|---------|---------|
| 简单 | 4 正确高亮闪烁，2 干扰灰暗标「无关」 | 无时间压力，全引导 | 必 VERIFIED |
| 普通 | 6 点微光，不区分正/干扰 | 70% 概率提示「袖口可能只是穿久了」；30% 误导「他走路好像有点跛？」 | 4正确+0干扰=VERIFIED；3正确±干扰=SUPPORTED；2=INSUFFICIENT；1↓=CONTRADICTORY |
| 困难 | 无提示，6 点全靠发现 | 70% 混入深度干扰（药房收据） | 同上四档，判定更严 |

### 4.4 推理墙验证（`MESSENGER_REASONING`）
- 集齐 6 → `_on_messenger_all_recorded()` → `_show_messenger_reasoning_wall()`。
- 假设板：M-01 锚文身 / M-02 络腮胡 / M-03 站姿 / M-04 发号施令（正确）+ M-05 袖口 / M-06 跛行（干扰）。
- **首次展示四级验证体系说明**（08 L490–494）：VERIFIED / SUPPORTED / INSUFFICIENT / CONTRADICTORY。
- **≥ SUPPORTED** → 解锁委托信 + 调查进度首次更新（右上角进度条微亮）。
- **< SUPPORTED** → 允许返回重探，不扣分（08 L500–502）。

### 4.5 信使收尾对话（08 L508–540，按难度不同）
```
简单：信使"太对了！您也像福尔摩斯先生一样厉害！" → 福尔摩斯"观察和推理，不是魔法，只是方法。"
普通（提示触发）：福尔摩斯"信号和噪音的区别——这是侦探的第一课。"
困难：信使惊奇，福尔摩斯几乎不评价，留待玩家自检。
```

### 4.6 推进
验证 ≥ SUPPORTED → `_show_commission_letter_dialogue()`。

## 5. 阶段 4 · 案件委托信 + 双钩子 + 三星评价（`RATING`）

### 5.1 委托信解锁（08 L542–596）
- 信使验证通过 → `ClueSystem.collect_clue_from_catalog("commission_letter", ...)` 解锁「案件委托信」。
- **对话**：福尔摩斯「信使留下的，是葛莱森警长的委托信。花园街3号，一具男尸，无外伤——像是中毒。」→ 华生「所以真正的案子，从这一刻开始。」→ 系统「📜 案件委托信已解锁—记入侦探笔记」。
- **B-01 已取消**：文案中「[进入案件（承接/拒绝选择已取消，案件自动承接）]」，教学完成即自动承接（08 L558）。

### 5.2 双钩子（依据 02 §9 §11）
- **剧情钩子**：福尔摩斯「（瞥信，嘴角微扬）有意思——伦敦郊区发生了一起谋杀案，警方束手无策。」华生「你要去吗？」福尔摩斯「当然。正好——让你见识一下什么叫真正的侦探工作。」→ 指向场景二现场勘查。
- **谜题钩子**：系统「委托信上只有短短几行字——死者是谁？死在哪？怎么死的？（案件三要素待解）」→ 推理战场记录，场景二/三逐步解答。

### 5.3 调查进度更新
- 系统提示：当前案件=血字的研究；进度=案件调查开始（1/8）；下一阶段=现场勘查。

### 5.4 三星评价面板（`_show_rating()`）
- 观察之星 🔍（收集完整度+干扰识别）、推理之星 🧠（四级验证达成度）、洞察之星 💡（自主发现度+六步完成度）。
- 教学关评价仅作引导反馈，不计入总星级；华生+信使均 VERIFIED → 洞察里程碑「信号与噪音」。

### 5.5 推进
点「存档并进入场景二」→ `_accept_case()`。

## 6. 阶段 5 · 承接案件 → 进入场景二（`COMPLETE`）

- **取消 B-01 选择**：评分面板按钮直接 `_accept_case()`（自动承接+存盘+转 scene2），不再弹承接/拒绝框。
- `_accept_case()`：置 `COMPLETE` → `add_milestone("sc_01_completed")` → 自动存档（`SaveSystem.request_save`，游客跳过）→ `await` 短延时 → `SceneLoader.transition_to("res://scenes/scene2.tscn")`。
- **退出演出**（02 §9 §10）：信使离开 → 福尔摩斯拿起委托信 → 转场马车驶向劳瑞斯顿花园街，雨景渐入。
