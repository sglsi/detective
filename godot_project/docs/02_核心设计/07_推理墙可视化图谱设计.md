# 推理墙可视化图谱（关系网络视图）设计草案

> **文档定位**：本文为《血字的研究》推理墙的**可视化交互专项设计**，聚焦用户手绘草图所提出的关系网络呈现方式——以「人物 / 线索」为节点、以「实线 / 虚线 + 颜色」编码关系确定性与可信度、支持多图（多画布）与线索折叠展开。
> 本文与《06_推理墙运行机制》互为补充：06 规定后台逻辑与流程，本文规定**图谱视图的视觉语言与交互规范**。两者共享同一套数据（线索库、假设树、标签体系、四级验证体系），图谱视图是推理看板中心区的**一种可选呈现形态**，与现有假设树视图可并存切换。

---

## 一、设计目标与原则

1. **关系一目了然**：以网络图替代纯列表，让"哪条线索指向哪个人物、关系是否确定、可信度如何"在视觉上一眼可读。
2. **确定性可视化**：关系的"已确认 / 存疑"用**实线 / 虚线**区分；线索本身的**可信度**用**颜色**区分（红=存疑、绿=确定）。
3. **多粒度浏览**：单人物可独立成图（聚焦深查），也可多人同图并列（全局对比）——参照 XMind「多画布 / 仅显示该分支」。
4. **可折叠减负**：线索节点可折叠成"簇"，展开看明细——参照 XMind「折叠 / 展开」与「外框」。
5. **与逻辑闭环不脱节**：图谱上的每一条关系都映射回《06》的四级验证体系，是同一套后台计算的前端呈现，不是独立数据。

---

## 二、设计灵感来源（XMind 范式参照）

| XMind 特性 | 在推理墙图谱中的对应 | 说明 |
|-----------|---------------------|------|
| **联系（Relationship）** | 自由连线 | 任意两个节点间自定义连线，可设线条样式、颜色、箭头、文字标签 |
| **折叠 / 展开** | 线索簇折叠 | 折起子节点显示数量徽标，点击一键展开 |
| **多画布（Sheet）** | 人物分图 | 一个案件可多张图谱，按人物或主题拆分，互跳 |
| **外框（Boundary）** | 人物关系簇 / 事件组 | 将相关节点圈选分组，注释分组含义 |
| **概要 / 标签 / 标记** | 可信度标记、状态标记 | 在节点上叠加状态（已验证 / 存疑 / 失效）与可信度色 |
| **ZEN 模式 / 仅显示该分支** | 聚焦单人物图 | 隐藏无关节点，只渲染当前关注链路 |

> 不照搬 XMind 的自由排版（那是 OFF 文档工具），游戏内采用**受控自动布局 + 手动微调**——节点初始由力导向/层级算法摆放，玩家可拖拽调整，避免节点重叠失控。

## 三、视觉语言规范

### 3.1 节点语义

| 节点类型 | 形状 | 默认配色 | 内容 | 来源 |
|----------|------|----------|------|------|
| **人物节点（Person）** | 圆角矩形 / 头像框 | 暗金边框 | 姓名 + 身份（嫌疑人 / 被害人 / 证人）+ 一句话画像 | 案件配置 `suspects` / `victim` |
| **线索节点（Clue）** | 卡片 | 边框色随可信度（见 3.3） | 线索名 + 来源标签 + 可信度档 | 线索库 |
| **假设节点（Hypothesis）** | 菱形 / 六边形 | 边框色随验证等级（06 §2.3） | 假设文本 | 假设树 |

> 人物节点是图谱的**锚点**：每个案件的人物节点固定摆放在图谱外圈或顶部，线索挂在对应人物之下，形成"人物为中心"的星型结构（与用户草图一致）。

### 3.2 连线语义（确定性 × 关系类型）

连线的**线型**编码"关系是否确定"，**颜色**编码"关系性质 / 可信度方向"。

| 线型 | 含义 | 触发条件 |
|------|------|----------|
| **实线** | 关系已确认（玩家或系统已判定确定） | 线索「已验证」后连出；或玩家在连线时标记为"确定" |
| **虚线** | 关系存疑 / 待验证 | 线索未验证；或玩家连线时未勾选"确定" |

| 颜色 | 含义（关系性质 / 可信度指示） |
|------|------------------------------|
| **绿色** | 支持 / 确定（该线索支撑此人物或假设） |
| **红色** | 矛盾 / 存疑（冲突、或线索本身可信度低指向此人存疑） |
| **橙色** | 反对（线索指向排除此人） |
| **灰色** | 弱关联 / 待归类（还没判明方向） |

> 与《06》现有自由连线代码映射：`support`→绿色实线、`oppose`→橙色虚线、`contradict`→红色虚线、`relate`→灰色虚线。本草案在此之上**引入"确定性"维度**：同一 `support` 关系，若线索已验证则升级为实线，未验证则保持虚线（见 §3.4 状态机）。

### 3.3 可信度色阶（应用于线索节点边框 + 关系线底色调）

| 可信度档（06 §3.1） | 节点边框色 | 关系线语义 |
|---------------------|-----------|-----------|
| 高（直接物证 / 专业检验） | 绿色 | 该线索连出的线偏向"确定可信" |
| 中（无利害关系目击） | 黄色 | 中性 |
| 低（二手传闻 / 嫌疑人自述） | 红色 | 该线索连出的线默认"存疑"，强制虚线 |

> 困难模式按《06》难度表**不显示可信度标识**，图谱视图同样隐藏色阶，仅以线型（实/虚）保留确定性信息，留给玩家自行判断。

### 3.4 节点状态 × 连线线型 状态机

```
线索状态(06 §2.1)        连线默认线型        说明
─────────────────────────────────────────────────────────
已收集(未验证)    ──▶     虚线              关系存疑，待验证
已验证           ──▶     实线              关系确定，绿色系
已失效           ──▶     灰色虚线(极淡)    失去证明力，仅作记录
玩家手动"标记确定" ──▶    实线              覆盖默认（即便未验证，玩家自信判定）
```

## 四、图谱结构（按用户草图建模）

### 4.1 单人物星型图（默认聚焦视图）

```
            ┌──────────┐
            │ 线索A(绿) │━━━━(实线·支持)━━┓
            └──────────┘                 ┃
            ┌──────────┐                 ┃
            │ 线索B(红) │╌╌╌(虚线·存疑)╌╌╌┫
            └──────────┘                 ┃
                                         ▼
                            ┌──────────────────────┐
                            │   人物节点：德雷伯     │
                            │   (被害人 / 嫌疑人)   │
                            └──────────────────────┘
                                         ▲
            ┌──────────┐                 ┃
            │ 线索C(黄) │━━━━(实线·反对)━━┛
            └──────────┘
```

- 人物节点居中，线索环绕。
- 点击人物节点可**折叠**其全部线索为簇（显示"N 条线索"徽标），再点展开。

### 4.2 多人物并列图（全局对比视图）

所有人物节点并排为"锚点列"，各自线索挂于其下；跨人物的共同线索（如"车轮印"同时指向两人）可拉一条**跨锚点联系线**（灰色虚线 `relate`），用于对比"同一证据如何指向不同人"。

> 对应 XMind「多画布」的**替代方案**：游戏内不强制真分文件，而是用**视图切换**（单人物聚焦 / 多人并列）实现同效，避免存档碎片化。若某案件人物极多（>4），再启用真正的"分图"（每张图一个人物 + 其直接线索），通过顶栏 Tab 或"仅显示该分支"跳转。

## 五、交互规范

### 5.1 视图切换
- 顶栏新增「视图：图谱 / 假设树」切换（与现有假设树视图并存，不冲突）。
- 图谱视图内再提供「聚焦单人物 / 全部人物」子切换。

### 5.2 连线交互（沿用并扩展《06》自由连线）
- 开启「🔗 连线」后，从节点拖到另一节点建立关系（现有行为不变）。
- **新增"确定性"选择**：连线结束时若两端均为线索 / 线索↔人物，弹出一个轻量浮层让玩家点选「确定(实线) / 存疑(虚线)」；或按住 `Shift` 默认"存疑"、不按默认"确定"，与现有 Shift=反对 约定区分（建议：连线结束浮层二选一更清晰，避免快捷键过载）。

### 5.3 折叠 / 展开（XMind 式）
- 人物节点 / 线索簇节点右上角显示折叠角标，点击切换。
- 折叠态：隐藏子节点，节点显示"▸ N"数量徽标（如"▸ 7 条线索"）。
- 支持「一键折叠全部 / 展开全部」（顶栏按钮）。
- 折叠状态随存档持久化（扩展 `_state_store["graph_collapsed"]`）。

### 5.4 画布操作
- 滚轮缩放、拖拽平移（沿用《06》 M1 摄像机方案 `_world` 容器缩放等价替代，不用 Camera2D）。
- 节点可手动拖动微调位置，位置记忆进存档。
- 悬停节点高亮其所有连线（其余淡化），便于在密集图中聚焦一条链路。

### 5.5 图例与外框
- 左下角常驻**图例**：实线=确定 / 虚线=存疑；绿=支持 / 红=矛盾存疑 / 橙=反对 / 灰=弱关联。
- 可选「外框」将一组相关节点圈选并加文字注释（如"马车夫作案链"）。

## 六、与《06》机制的衔接（关键约束）

1. **数据同源**：图谱节点全部来自《06》既有数据——人物来自案件配置 `suspects`/`victim`，线索来自线索库，假设来自假设树；不新建数据表。
2. **验证闭环**：图谱连线经现有 `_contradiction_signals()` / `_support_signals()` 流入 `get_verdict()`（已在 v1.4 打通）。本草案新增的"确定性线型"只影响**呈现**，不改变验证计算；验证仍以线索状态与关系类型为准。
3. **难度适配**：困难模式隐藏可信度色阶（§3.3）；简单模式可默认展开全部线索并高亮已验证线索的实线。
4. **存档**：新增图谱专属状态（视图模式、折叠态、节点位置、确定性覆盖标记）写入 `_state_store`，与现有 `relations` 字段并列。

## 七、分阶段实现建议

| 阶段 | 范围 | 说明 |
|------|------|------|
| **MVP（图谱 1.0）** | 单人物星型图 + 线索折叠 + 实/虚线（按线索状态自动）+ 图例 | 先落地"人物为中心 + 可折叠 + 线型区分确定性"，不动可信度色阶与多图 |
| **M2+（图谱 2.0）** | 多人并列图 / 真分图、可信度色阶、连线确定性浮层、外框注释、跨锚点联系线、节点手动布局记忆 | 完整 XMind 式能力 |

> 注：现有《06》自由连线（v1.4 落地、v1.5 修崩溃）已具备"拉线 + 关系类型着色"骨架，本草案的图谱视图是在其上补**人物锚点 + 确定性线型 + 折叠 + 多图**四块拼图。

## 八、待确认 / 开放问题

1. 人物节点的"身份"分类（嫌疑人 / 被害人 / 证人）由案件配置提供，还是图谱内可玩家自定义？→ 倾向**配置提供**（与数据同源原则一致）。
2. 跨人物"共同线索"联系线是否默认显示，还是需玩家手动拉？→ 倾向**手动拉**（避免默认图过乱），但求助扫描时可高亮提示。
3. 折叠态下"N 条线索"是否计入验证？→ 折叠仅视觉，验证照常计算（与 XMind 折叠不影响数据一致）。
