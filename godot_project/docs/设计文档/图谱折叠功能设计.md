# 推理墙 · 图谱折叠功能设计

> 设计依据：XMind 的连线折叠控件（父节点到子节点的连线出口处放置 `−`/`+N` 圆形控件，点击折叠/展开）。
> 适用对象：`scripts/clue/graph_view_controller.gd`（图谱视图叠加层）。
> 设计目标：让玩家在破案过程中，把暂时不关心的证据簇收起，减少视觉与认知负荷；折叠状态随存档保存/恢复。

---

## 1. 核心概念

### 1.1 圈层深度（`ring_depth`）

本图谱的节点按 `_RING_BANDS` 半径带天然分层：

| kind | ring_depth | 说明 |
|------|------------|------|
| `person`（焦点人物） | 0 | 星型中心，最内层 |
| `conclusion` / `chain` | 1 | 核心结论/推理链 |
| `hypo`（推断） | 2 | 中间层 |
| `clue`（线索） | 3 | 最外层 |

### 1.2 边的方向归一化

自动推断边已满足"外→内"：

- `clue → hypo`（线索支撑推断）
- `hypo → conclusion`（推断支撑结论）

玩家手动建立的关系 `_relations`（`support / oppose / contradict / relate`）不预设方向，统一按圈层归一化：

```gdscript
if ring_depth(from) >= ring_depth(to):
    forward = (from -> to)   # 外指向内
else:
    forward = (to -> from)   # 反转为外指向内
```

### 1.3 折叠语义

折叠节点 N：隐藏其**向外子树**，即所有从 N 出发沿归一化边可达、且 `ring_depth > ring_depth(N)` 的节点（递归 BFS）。

- 折叠某条「推断」→ 收起所有指向它的线索；
- 折叠「结论」→ 收起全部推断+线索；
- 折叠「焦点人物」→ 等价现有 `_folded_persons` 行为（收起其关联线索）。

> 最外层 `clue`（ring_depth=3）没有更外层，因此无折叠控件。

## 2. 交互设计：XMind 式连线控件

### 2.1 控件形态

在**父节点（内层节点）到子节点（外层节点）的连线出口处**放置一个圆形控件：

| 状态 | 视觉 | 含义 |
|------|------|------|
| 展开 | 小圆圈，内部 `−` | 点击收起外层内容 |
| 折叠 | 小圆圈，内部 `+N` | 已隐藏 N 个外层节点；点击展开 |

- 控件位于父节点外缘，朝向子节点簇的重心方向；
- 控件半径约 10–12 px，便于触达；
- 鼠标悬停显示 tooltip："点击折叠外层内容" / "点击展开（已隐藏 N 项）"。

### 2.2 触发方式

1. **点击控件**：toggle 折叠/展开；
2. **不引入右键菜单项**：右键继续保留现有标签/删连线功能；
3. **顶部 🪗 折叠按钮升级**：当前只折叠焦点人物。升级后：若当前有高亮/选中节点则折叠该节点，否则折叠焦点人物。

### 2.3 视觉反馈

- 折叠根节点自身保持可见，描边变为暗金虚线（`COL_GOLD` + dash），提示"此节点下有收起内容"；
- 被隐藏节点及其相关边不绘制；
- 若某条边的两端均可见，则正常绘制；
- 折叠时 toast："已折叠「推断 A」的外层内容（N 项）"；展开时："已展开「推断 A」"。

## 3. 数据结构

### 3.1 新增状态

```gdscript
# graph_view_controller.gd
var _folded_nodes: Dictionary = {}       # node_id -> true，被折叠的"根"节点集合
var _all_positions: Dictionary = {}      # node_id -> Vector2，全部节点的位置缓存（含隐藏者）
```

### 3.2 持久化

写入 `_state_store`：

```gdscript
func _persist_view() -> void:
    _state_store["graph_view_mode"] = _mode
    _state_store["graph_focus"] = _focus_person
    _state_store["graph_seed"] = _layout_seed
    _state_store["graph_folded_nodes"] = _folded_nodes
    _persist_node_positions()   # 改为持久化 _all_positions
```

读档恢复：

```gdscript
func build(data: Dictionary) -> void:
    # ...
    _folded_nodes = _state_store.get("graph_folded_nodes", {})
    # 向后兼容：旧键 graph_folded_persons 存在则并入
    var old_fp = _state_store.get("graph_folded_persons", {})
    for pid in old_fp:
        _folded_nodes[pid] = true
```

### 3.3 与 reasoning_wall 的 state_store 关系

本控制器只负责把 `graph_folded_nodes` 写回 `_state_store`；`reasoning_wall._persist_state()` 已修复（不再 `clear()` 整个 `_state_store`），因此关系/位置/折叠状态会一起落盘。读档时 `reasoning_wall` 把同一份 `state_store` 传回 `build()` 即可恢复。

## 4. 算法

### 4.1 折叠隐藏集合

```gdscript
func _compute_hidden() -> Dictionary:
    var hidden := {}
    var outward := _outward_edges()  # 归一化后的 外->内 邻接表
    for root in _folded_nodes:
        var stack := [root]
        while not stack.is_empty():
            var cur: String = stack.pop_back()
            for nxt in outward.get(cur, []):
                if hidden.has(nxt): continue
                if _ring_depth(_node_kind.get(nxt, "")) <= _ring_depth(_node_kind.get(root, "")):
                    continue
                hidden[nxt] = true
                stack.append(nxt)
    return hidden
```

### 4.2 节点与边过滤

- `_node_list()` 在返回列表前过滤掉 `hidden` 中的节点；
- `_derive_edges()` 过滤掉任意端点在 `hidden` 中的边。

### 4.3 控件数量与位置

每个**未被隐藏**且 `ring_depth < 3` 的节点，若其存在至少一个直接外层邻居，则生成一个折叠控件：

```gdscript
func _fold_control_pos(node_id: String) -> Vector2:
    var center: Vector2 = _node_center.get(node_id, Vector2.ZERO)
    var kind: String = _node_kind.get(node_id, "")
    var neighbors := _direct_outer_neighbors(node_id)
    if neighbors.is_empty(): return center

    # 取所有指向外层邻居的向量均值，得到"出线方向"
    var dir := Vector2.ZERO
    for nb in neighbors:
        dir += (_node_center.get(nb, center) - center).normalized()
    dir = dir.normalized()

    var radius: float = _node_radius_for_kind(kind)
    return center + dir * (radius + 14)
```

控件随节点拖动实时更新位置（在 `_input` 拖动分支与 `_rebuild_graph` 后同步）。

## 5. 控件实现细节

### 5.1 控件层级

- 控件为 `Control` 节点，作为 `_canvas` 的子节点（与节点同级但后添加，保证在上层）；
- `mouse_filter = MOUSE_FILTER_STOP`，独立处理 `gui_input`；
- 控件不继承节点卡片的 `gui_input`，因此点击控件不会触发节点拖动或连线模式。

### 5.2 控件状态切换

```gdscript
func _make_fold_control(node_id: String) -> Control:
    var c := Control.new()
    c.custom_minimum_size = Vector2(22, 22)
    c.position = _fold_control_pos(node_id) - Vector2(11, 11)
    c.gui_input.connect(_on_fold_control_gui.bind(node_id))
    c.draw.connect(_draw_fold_control.bind(node_id))
    return c
```

`_draw_fold_control` 中根据 `_folded_nodes.has(node_id)` 画 `−` 或 `+N`。

### 5.3 与拖拽的关系

- 鼠标按下落在控件上 → 控件截获，toggle 折叠；
- 鼠标按下落在节点本体 → 仍走 `_on_node_gui` 的 move/edge 逻辑；
- 连线模式下点击控件 → 不进入 `_handle_connect_click`。

---

## 6. 位置保持

关键：被折叠节点不能丢失位置。

- `_all_positions` 在 `_compute_layout` 后立即初始化全部可见节点位置；
- 节点被拖动时同步更新 `_all_positions[id]`；
- `_persist_node_positions` 序列化 `_all_positions`；
- 节点从折叠恢复时，`_compute_layout` 从 `_state_store["graph_node_positions"]` 读取位置，不再重新计算默认排布。

## 7. 模式与状态兼容

| 模式/状态 | 折叠支持 |
|-----------|----------|
| Mode C 人物星型 | 完整支持 |
| Mode B 推理链分层 | 完整支持（圈层语义一致） |
| Mode A 全局 DAG / Mode D 折叠摘要 | 禁用，提示"该视图暂未开放" |
| State.EDITABLE | 支持折叠、展开、拖动 |
| State.LOCKED / 已出 verdict | 支持折叠/展开（浏览），仅禁改关系/拖动 |

## 8. 撤销 / 重做

`toggle_fold(node_id)` 通过现有 `UndoRedo` 入栈：

- do：把 `node_id` 加入 `_folded_nodes`，`_rebuild_graph()`；
- undo：从 `_folded_nodes` 移除，`rebuild_graph()`。

与节点移动、连线共用同一 undo 栈，支持 Ctrl+Z / Ctrl+Y。

---

## 9. 已知坑与规避

1. **控件必须 `MOUSE_FILTER_STOP`**：否则点击会穿透到 `_canvas` 触发平移/连线。
2. **控件位置要同步拖动**：`_input` 中 move 拖动节点时，同步更新该节点折叠控件坐标。
3. **隐藏节点位置不能丢**：依赖 `_all_positions` 解决，避免展开后节点跳回默认位（同 Bug1 位置持久主题）。
4. **计数 `N` 取直接外层邻居数**：避免递归总数过大；tooltip 可显示"含间接节点 X 个"。
5. **旧存档兼容**：`graph_folded_persons` 并入 `graph_folded_nodes`，避免玩家旧档丢失折叠状态。

## 10. 验收标准

新增回归测试 `scripts/test_graph_fold.gd`：

1. 折叠某 `hypo` → 其外层 `clue` 不在 `_node_views`，相关边不在 `_edge_list`；
2. 点击该 `hypo` 的折叠控件 → 仅触发折叠/展开，不触发拖动；
3. 展开后节点位置与 `_all_positions` 折叠前一致；
4. `_persist_view` 后 `_state_store["graph_folded_nodes"]` 含该 `hypo`；重新 `build` 后折叠仍在；
5. 旧 `graph_folded_persons` 可迁移为 `graph_folded_nodes`。
