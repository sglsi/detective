# 华生（Watson）可绑骨肢体部件素材规格书

> 用途：交给生图 AI 按此规格产出华生可绑骨肢体部件图，直接进入 `SkeletonCharacter2D` 骨架动画管线（与福尔摩斯同一套），无需手工调参。接入点：`PortraitLibrary.get_rig("华生")`。
> 踩坑前提：福尔摩斯首版因「抠图光晕 + 肢体未顶满画布 + 关节偏位」导致部件缩到不可见/脱节。本规格全部为硬约束，目的是让自动生成器算出的 `scale/pivot` 直接正确。

---

## 1. 交付物（放入 `assets/characters/watson/rig/`）

| 文件名 | 对应骨 | 必需 |
|---|---|---|
| `watson_head.png` | head（含颈根） | 必需 |
| `watson_torso.png` | torso（肩→胯） | 必需 |
| `watson_upperarm_L.png` / `watson_upperarm_R.png` | upperarm | 必需 |
| `watson_forearm_L.png` / `watson_forearm_R.png` | forearm | 必需 |
| `watson_thigh_L.png` / `watson_thigh_R.png` | thigh | 必需 |
| `watson_shin_L.png` / `watson_shin_R.png` | shin | 必需 |
| `watson_hat.png` | hat（可选） | 可选 |

共 10 必需 + 1 可选；`_L/_R` 为左右镜像件。

---

## 2. 统一视角（最关键，本次预览失败根因）

- **全部 11 个（含可选 hat）部件必须采用同一个正面视角**（允许极轻微 3/4，禁止侧脸、禁止背面）。
- **头、躯干、四肢、帽子视角必须一致**：头不能是侧面轮廓，帽子不能是俯视/顶视示意图。
- 理由：部件在引擎里按同一骨架拼合，视角不一致会直接脱钩、无法同框（本次预览头侧脸、帽俯视即此问题）。

---

## 3. 绘制规范（生图必须遵守）

### 3.1 竖直 + 近端关节在顶边正中
- 每个肢体**竖直绘制**：与父骨连接的「近端关节」位于图片**顶边水平正中央**，肢体向正下方延伸到近底边。
- 例：`upperarm` 肩端在顶中、肘端在底中；`thigh` 胯端在顶中、膝端在底中。
- 禁止画成斜的或 A-pose 外展——pose 由骨架旋转去摆，画斜会双重旋转脱节。

### 3.2 内容顶满画布（留白 ≤ 5%）
- 肢体实物从顶边延伸到接近底边，上下透明留白合计 ≤ 5% 高度。
- 自动生成器用 `scale = 骨长 / 整图高度`：若实物只占中间 30%，渲染后肢体只剩骨长 30%，关节间出现大空隙 → 不可见。
- 若生图工具只能出方形大图，请生成后**紧裁**到肢体自然比例再交付（见 §5 尺寸）。

### 3.3 近端关节必须在顶边水平正中央
- 生成器取「顶部 6% 行」不透明像素水平质心作 pivot；关节偏左/右 → 部件整体横移。
- 躯干/头左右对称，顶中即脊柱/颈中线；四肢肩/肘/胯/膝画在顶中。

### 3.4 左右件互为水平镜像
- 正面视角下角色左臂出现在画面右侧。`_L/_R` 是同一肢体左右镜像，分别产出两幅（先画一侧再水平翻转）。管线对四肢不做翻转。

### 3.5 禁止任何参考叠加
- **禁止**骨骼线、骨架、网格、关节十字标记 `+`、对位参考等任何非角色内容。只交付干净的最终成片像素美术。
- （与福尔摩斯手工定位流程不同：华生走自动生成，叠加物会被当成内容撑满画布。）

### 3.6 相邻关节画弧形遮挡边
- 上臂↔前臂、大腿↔小腿、躯干↔头在关节处各自画出被对方轻微遮挡的弧形边缘（非直切矩形），旋转时不露白。

---

## 4. 图片格式硬性要求

| 项 | 要求 |
|---|---|
| 容器 | PNG-24（RGBA），`load` 直接可用 |
| 背景 | **真·透明**（alpha 通道），禁止绿幕/蓝幕/纯色底，禁止后期抠图 |
| 透明边缘 | **硬边缘**（alpha 0/255 为主，抗锯齿 ≤1–2px）；禁止柔光晕、半透明雾化、投影光环（会被当内容撑满画布） |
| 色彩 | sRGB，8bit/通道 |
| 压缩 | 无损 PNG，无 JPEG/有损重压 |
| 分辨率 | 长边 512–2048px；按 §5 紧裁 |
| 命名 | 严格按 §1（小写、下划线、`watson_` 前缀） |

---

## 5. 尺寸与比例（强制）

参考身高站立约 7.5 头身；各部件**高度比应 ≈ 骨长比** `head:torso:upperarm:forearm:thigh:shin ≈ 80:110:60:55:80:80`。

| 部件 | 紧裁画布 (宽×高, px) | 顶边=近端 | 底边=远端 |
|---|---|---|---|
| head（含颈根） | 256 × 336 | 颈根（顶中） | 下巴 |
| torso（肩→胯） | 208 × 464 | 肩/锁骨（顶中） | 胯（底中） |
| upperarm_L/R | 112 × 256 | 肩（顶中） | 肘（底中） |
| forearm_L/R | 96 × 232 | 肘（顶中） | 腕（底中） |
| thigh_L/R | 144 × 336 | 胯（顶中） | 膝（底中） |
| shin_L/R | 120 × 336 | 膝（顶中） | 踝（底中） |
| hat（可选） | 480 × 192 | — | 帽檐在下、与头同视角 |

- 宽度为按 §2 同一正面视角下的自然粗细；**关键是高度方向内容顶满**（§3.2）。
- 表中尺寸已放大到清晰档；若生图工具出方形图，请紧裁到此比例再交付。

## 6. 美术风格

- 维多利亚（贝克街侦探事务所），与福尔摩斯立绘**成对的写实/插画风**，同框不违和。
- 华生特征：军人气质、圆润脸、八字胡；常着深褐/暗红外套 + 棕格纹马甲 + 白衬衫 + 黑领结；帽子为猎鹿帽或圆顶礼帽（可选）。
- 统一光源左上 45°，所有部件阴影朝右下；统一 1–2px 深棕描边。
- 配色：外套褐、马甲棕格、肤色一致、裤深藏青近黑；与福尔摩斯保持同一线宽、同一光影方向。
