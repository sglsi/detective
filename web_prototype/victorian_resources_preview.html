🎨 生成方法

这两个资源使用 像素艺术风格生成器 skill 生成，工作流程如下：

📋 工作流程

# 1. AI 生成绿幕图
generate_image(prompt="<元素> alone, pixel art style, <尺寸> sprite, 
clean solid color background (pure green #00ff00), 
NO other objects, isolated, game asset")

# 2. Python 抠图 + 像素化
python3 skills/pixel_art_generator/scripts/pixel_art_cutout.py \
  --input <绿幕图.jpg> \
  --output <输出.png> \
  --pixel-size <尺寸> \
  --colors <颜色数>
